### 每日执行顺序与调用入口

撤退与追击的 850 项全表扫描不是孤立代码，也不是逐旬入口。旧 IDB 把 `0x50A168..0x50A23F` 错定义成单个数据项，遮蔽了 `process_simulation_stage_task_state(0x50A170)`。恢复代码后可见两个普通相对调用：

- 状态 1001：`0x50A1A6 -> process_unit_autonomous_retreat_updates(0x453B20)`；
- 状态 1002：`0x50A1B2 -> process_unit_pursuit_updates(0x453B50)`；
- 状态 1003/1004：建立并消费后续部队任务。

`vftable_simulation_stage_task(0x610AC4)` 的 `+0x0C` 槽直接保存 `0x50A170`。外层 `process_simulation_state_machine(0x50A760)` 在阶段 1001/1002 创建 `simulation_stage_task`；该任务完成后，外层阶段 1005 调用 `advance_date_and_run_daily_updates(0x50A340)` 将日期推进一天。若新日期不是旬首，外层状态回到 1001，创建下一日的同类任务。因此两次扫描在每个模拟日各执行一次，顺序固定为先撤退、后追击。

这也解释了 `RE-SAN9PK-0087` 的零命中：绝对地址原始字节搜索无法发现 `E8 rel32`；已解码指令操作数扫描又因调用者整段被定义为数据而没有遍历这两条指令。该批的审计过程可复现，但“普通直接引用已排除”的结论失效。

取证身份：RE-SAN9PK-0090。

### 响应变量与评估口径

本记录收窄 `handle_unit_enemy_approach_response(0x464910)`、`handle_unit_autonomous_retreat_response(0x464E00)` 的核心 `0x464E08`，以及 `handle_unit_pursuit_response(0x465160)`。三者是部队运行时规则，不因函数位于模拟链中就直接归类为 AI 专用决策。

下文使用：

- `A`：本队主将人物运行时 `+0x78` 的性格值；
- `T`：本队兵力，即部队虚表槽 `+0x80` 的返回值；
- `M`：本队士气，即部队虚表槽 `+0x84` 的返回值；
- `E`：相邻对立部队经候选谓词过滤后的兵力和；
- `R`：敌接近分支中 `muldiv(本队虚槽 +0x8C 返回值, 100, max(1, 候选敌队同槽返回值))`。

`+0x8C`为基础战力乘兵力除100、至少取1的总战力评估；汇编栈平衡证据见[事后命令](#re-0081-2026-09-13事后命令与战力评估补核)。

### 敌接近：感知、选敌与策略服从

入口要求本对象事件38/39、状态1/8，排除旗标mask`0x300000`、交战虚槽`+0x90`及当前／主目标已经在候选表等情形。`0x474C00`排除mask2、要求mask8，再走感知`0x464800`；`0x474C50`排除守军mask1，允许与当前／主目标同根或公共敌对对象。

**2026-10-24实现续核，2026-10-25状态更新。**`0x464910`的交战虚槽明确解析为`0x461730`，本队主动或被动交战均阻止后续改指裁决；这不能用“已有临时迎击目标”代替。普通返回39仍可进入，不能连同自主返回52一起排除。当时实现的返回身份与交战门遗漏已由`AutonomousReturn`及相应测试修复，历史公开对照保留在[公共响应续核](audits/responses.md#note-2026-10-24-automatic-work-response-audit)。本轮直接核实迎击每日执行，原作未设置“中止临时追击后同日不再迎击”门；v190已改为每日执行并撤销旧抑制描述，同时按下述视野和优先级替换统一感知半径与最近优先。

感知取本队阵形（守军取建筑阵形），阵形无效或27则否；目标须有效且为守军或活动野战单位。中心距离不超过`5×阵形视野半径+部队视觉宽度`，随后以本队朝向和阵形视角判扇区：8全向，1～7按16方向相对夹角，其他否。视觉宽度零兵为0，其余随6000/12000/20000/30000/40000/50000门递增为4～10。

候选比较器`0x474630`为`max(0,当前单兵基础战力−(主将身份0?20:0))×兵力`，稳定降序取首，**不是最近敌队**；函数没有随机调用。

对策略位 `0x1000`（敌接近时攻击）和 `R/A` 的裁决如下：

| 策略位 | 条件 | 可见写回 |
| --- | --- | --- |
| 开 | `A < 2`，或 `R + (A == 2 ? 25 : 0) > 100` | 先执行公共状态清理，再把当前目标编号写成候选敌队编号，并把辅助目标字段清零 |
| 开 | 其余 | 不改上述目标字段 |
| 关 | `A` 不是 2/3，且 `limsub(R, A == 1 ? 25 : 0) >= 100` | 同上，改指候选敌队并清零辅助字段 |
| 关 | 其余 | 不改上述目标字段 |

四种结果分别使用消息对 `10145/10052`、`10154/10053`、`10163/10054`、`10172/10055`。消息资源语义已核对：10052依方针进攻、10053无视方针避战、10054依方针避战、10055无视方针进攻；10145等为按性别／性格分流的对白，不应只取其中一条文本。两个不改指的避战分支只在原mask`0x800000`置位时发消息，改指攻击分支不受该重复抑制。

<a id="re-0119-2026-09-13-自动选敌与被攻击反击的区别"></a>
### 外交敌对、明确攻击与被攻击反击

**事实，静态调用与连续指令核对：**公共势力敌对谓词 `0x4453E0` 先拒绝无效/同根势力，再排除双方同属联盟成员或盟主、存在攻击请求配对，最后要求关系档小于2，即关系0..39。关系40..100（包括中立）不会单凭接近成为普通外交敌人。`0x445460` 为单位包装，`0x445490` 为建筑包装；这些入口被主库其他函数范围覆盖，不能直接采信对该地址返回的无关大型反编译，故本轮以真实入口连续指令及调用目的地址确认。

野战接近响应 `0x464910` 经回调 `0x474C00` 检查活动/接近条件，经 `0x474500` 排除同势力，再经 `0x474C50` 筛选候选。后者既允许公共敌对谓词 `0x45E180 → 0x45E100 → 0x445460` 成立，也允许候选与自身意图目标或当前目标同属一个根势力。因此“关系40以上或同盟”仅阻止普通自动选敌，不能推翻已有明确攻击命令。响应还受当前命令/状态、接近策略、主将性格、总战力评估比、已有目标等限制；外交敌对不是保证当日自动攻击的充分条件。

普通设施的每日自动目标由 `0x50B1B0 → 0x438750 → 0x474370` 产生，需要有守兵、有效活动单位、`0x435810 → 0x4357C0 → 0x445490 → 0x4453E0` 的敌对资格及设施射程。工作物运行时类型7..10有单独放行分支，不把它们和普通城池/据点混为一谈。故仍同盟时，即使野战交战令关系降至39，附近普通设施也不会仅据低关系自动选中盟友部队。

**反击是另一条规则。**`0x49B460` 状态1005计算被攻击方反击伤害时只通过 `0x465970` 检查反向射程，并在原始状态6（混乱）或7（溃败）时将反击兵损置零。`0x465970 → 0x465860` 的野战分支要求有效目标、反击方兵力为正、相应有效标志及射程；设施分支经 `0x465940` 转附属单位，公共设施射程见 `0x438690`。此处不读取关系档位、联盟或攻击请求身份，也不要求B预先有攻击A的命令。

因此A明确攻击原盟友/友好势力B的部队，B仍可在同一普通攻击结算中还手；超出B射程、B无兵或混乱/溃败等情况不会造成普通反击兵损。高关系但无联盟/请求的双方，交战关系降到39后，还会获得普通自动选敌的外交资格；仍同盟时该资格继续受联盟门阻止，但直接反击与既有明确目标不因此消失。上述为静态规则，不承诺每个兵法/特殊情境均等同普通反击。

取证身份：RE-SAN9PK-0119。

<a id="re-0081-事实自动撤退响应"></a>
### 每日自动撤退：条件与优先级

核心要求公共可处理谓词成立、对象类型不是 52、状态为 1/8、存在有效归属/返回对象和主将；类型 39/51 还要求一个关联索引不是 `-1`。随后汇总相邻对立部队兵力为 `E`，并按策略位 `0x2000`（自主撤退许可）裁决：

| 策略位 | 触发条件（按顺序，前项优先） | 消息对 |
| --- | --- | --- |
| 开 | `M < 4*A + 25` | `10181/10056` |
| 开 | `T < 300*A + 2000` 且 `E > T` | `10190/10057` |
| 关 | `A >= 2` 且 `M < 4*limsub(A,2) + 25` | `10199/10058` |
| 关 | `A >= 2` 且 `T < 500*(limsub(A,2)+3)` 且 `E > T` | `10208/10059` |

任一条件触发后，函数发出对应消息，调用公共状态清理，再通过 `0x4642B0` 构造指向有效归属/返回对象的事件记录、设置 `0x40000` 状态位并清理若干命令字段；返回 1。无条件触发时清理候选容器并返回 0。函数中没有随机调用。

许可关闭仍可能按性格分支撤退；兵力门同时要求E>T，士气门独立且优先。

取证身份：RE-SAN9PK-0081。

<a id="re-0090-自动撤退没有概率或冷却"></a>
#### 无随机、无冷却与次日重试

`handle_unit_autonomous_retreat_response(0x464E00)`及其每日扫描链不消耗随机。

条件不成立时，处理器不写入“上次判断日”、倒计时或其它冷却状态；下一模拟日会再次扫描同一活动部队。条件成立但 `try_set_unit_return_event(0x4642B0)` 转换失败时，同样没有冷却写回，因此只要部队仍满足入口条件，后续日期仍会重试。成功后则以事件类型和状态位排除重复处理，这属于状态转换，不是时间冷却。

取证身份：RE-SAN9PK-0090。

<a id="re-0090-返回事件的精确转换"></a>
#### 返回事件转换的前提与写回

`try_set_unit_return_event(0x4642B0)` 的机器边界是：

1. 当前命令/事件类型必须在闭区间 `38..52`；`-1` 或区间外类型直接返回 0；
2. 部队 `+0x64` 的关联返回对象必须有效；
3. `clear_unit_command(0x462670)` 将当前命令清为 `-1`；
4. `unit_return_event_ctor(0x46BF20)` 构造内部类型 `52`、目标为返回对象的事件；
5. `set_unit_command_event(0x461E40)` 写入事件，随后设置部队标志 `0x40000` 并清理辅助状态。

因此调试中看到的 `-1` 可以只是空命令或清理过程的哨兵；它本身不表示撤退概率失败。如果在调用 `0x4642B0` 前已经是 `-1`，本次转换确定性失败且没有返回状态写回。

这里的内部事件类型 52 与 `RE-SAN9PK-0089` 的交互工厂 code 52 不属于同一编号空间：交互 code 52 最终仍可构造命令类型 39，而本函数明确写入事件记录类型 52。

**2026-10-24实现续核，2026-10-25状态更新。**普通返回39与此处自主返回52的区别还由消费者互证：敌接近允许本队39，追击响应却要求对方52且带`0x40000`。当时合并返回身份的遗漏已修复，历史六项公开对照见[公共响应续核](audits/responses.md#note-2026-10-24-automatic-work-response-audit)。本轮进一步确认：事件52是持续返回身份，`0x40000`却在每日`50BD00`中清除，是短暂响应标志；v190新增独立的`PursuitResponsePending`，不再用持久`AutonomousReturn`替代两个语义。普通39／输送51的自主撤退还要求当前目标引用有效，主任务返回地／输送目的地本身不满足该门；详见[全面核对](../../notes/2026-10-25-unit-policy-ida-audit.md#追击持续返回身份与一次性触发不同)。

取证身份：RE-SAN9PK-0090。

### 每日追击：保持、中止与返回

入口要求运行时类型 38/39、状态 1/8，取得两条相关目标引用，并要求第二条引用是带 `0x40000` 状态位的类型 52 对象。令`same`表示有效主目标`0x4643F0`与当前目标`0x464430`解析为同一单位；建筑目标解析为其守军。下表“近邻10”指本队矩形向外扩50后与其他部队矩形相交，再筛已出发与公共敌对，**不是中心欧氏距离10**：

| 追击许可 `0x4000` | 条件 | 可见结果 |
| --- | --- | --- |
| 开 | `same` | 保持目标，结果 0 |
| 开 | 非 `same` 且 `A == 0` | 不清目标，结果 0 |
| 开 | 非 `same` 且 `A != 0` | 当前目标编号写 `-1`，辅助目标字段清零，结果 2 |
| 关 | `same` 且 `A == 0` 且近邻10候选表为空 | 不改目标，结果 1 |
| 关 | `same` 且 (`A != 0` 或近邻10候选表非空) | 调用 `0x4642B0` 进入返回对象相关状态，结果 3 |
| 关 | 非 `same` | 清目标，结果 2 |

结果0～3分别使用消息对`10217/10060`、`10226/10061`、`10235/10062`、`10276/10041`，资源语义为依方针追击、擅自追击、中止追击、依方针撤退；10056/57依方针撤退、10058/59擅自撤退也已在当前消息资源核对。函数没有随机调用，静态字段／消息分支已闭合，原游戏单变量局面实验仍单列AI-R11。

**2026-10-25直接续核。**`0x40000`在追击扫描之后的每日`0x50BD00`清除，不能视为整个自主返回期持续有效的响应门。近邻表`0x461CA0`只移除本队，不额外移除当前撤退目标；它仍在范围内并满足活动／敌对资格时，自身便能使表非空。因此禁止追击的A=0分支要求“近邻表为空”，不能改述为“没有其他敌军”。修复前持久触发及剔除目标的两处偏差已由公开日推进复现，v190已修正并将两例保留为正式回归，见[本轮诊断与实施](../../notes/2026-10-25-unit-policy-ida-audit.md)。

取证身份：RE-SAN9PK-0081。

### 原目标失效后的事后命令
