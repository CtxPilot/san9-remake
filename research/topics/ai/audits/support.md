### 建筑保留需求不是各工作统一的硬留兵

原作`4A90F0`只在建筑关系缓存mask2成立时设定保留需求；`4FDA70`封顶150000后向上量化为2500的整数倍。mask2表示领有建筑邻接非己方建筑，**有效空地也参与**，不能简化成仅邻接敌军。关系缓存mask10另扩展至同城／邻城，工作51的分组还独立检查所在城市及邻城有无非己方、非异民族建筑。

| 源建筑类别 | mask2不成立的需求 | mask2成立的原值 | 量化后需求 |
| --- | --- | --- | --- |
| 城市 | 0 | 40000 | 40000 |
| 港口（固定类型1） | 0 | 3000 | 5000 |
| 关（固定类型2） | 0 | 30000 | 30000 |
| 固定类型3设施 | 0 | 10000 | 10000 |
| 固定类型5／6设施 | 0 | 15000 | 15000 |
| 固定类型4及其他 | 0 | 0 | 0 |

以上为既有原作静态事实及量化计算，本轮未分别构造六种原作场景。[OriginalAiContentCompiler](../../../../src/San9.Importer.San9PkTc101/Scenarios/OriginalAiContentCompiler.cs)将版本分类转换为内容中的城市保留量与逐设施保留量；[BuildingReserve](../../../../src/San9.Application/AI/OriginalAiMilitary.cs)按同一量化规则读取。运行时不需要复制源分类编号。

| 港、关及可驻人普通设施，计划未搬空 | 同上 | 输送命令 | 同样只取一人，不套9／59的组队留人规则 |
| 非城市，计划等于全部当前现兵 | 同上，再过单人部署容量及公共资格 | 普通单人出阵，目标为入城／返回接收地 | 可带走唯一驻人；预算正值不保证实际保留表中的兵力 |

建筑保留量只是在账本计算中被扣除。原作`4BBA00`生产器仍重新读取来源现兵，不以预算夹取每次兵量；当前`Transport`也如此。特别是非城市只要求预算正数，没有城市的10000预算门。纯按这些静态公式，港口现兵5001、量化保留5000且无其他贡献时仍有正预算，若其他来源和配对资格成立，可计划搬空5001；这是公式推导例，**不是本轮动态复现**，也不能据此认定遗漏硬留兵限制。

选中配对后消费来源／目标。原作失败虚扣私有预算由B14采用反馈结算修正，路线失败由B24明确区分；本轮没有把这些已采用差异列为遗漏。非城市后备的零熟练度与选船旧问题仍见[选人与后备续核](planning.md#note-2026-10-23-automatic-work-selection-audit)，本轮未重复计数或重跑既有5000兵搬空测试。

<a id="note-2026-10-24-automatic-work-transport-reserve-audit-原作事实更正与b25差别"></a>
### 原作事实更正与B25差别

主代理本轮回读闭合以下静态事实：

- `4BBF50 → 475250 → 473CC0`枚举通用`CUnitData`，谓词只要求单位虚槽`+0x30`返回本上下文根势力且mask2清零，没有排除mask1内嵌驻军。单位域`453330`包含50座城市和200个地域对象的内嵌单位；城／地域加载的`43A8E0／4376C0`会给本方驻军写入根势力引用。
- 合格对象中事件40～43不计；事件51把现兵与伤兵全额计入目的地；其余把`floor((现兵+伤兵)/2)`记到`462740`解析的建筑。该解析器对野战单位使用当前格`unit+0x78 → 45C8A0`所在地域建筑，内嵌驻军则取`45DEF0`关联建筑。
- 完成通用单位累计后，再单独加入建筑自身`现兵+floor(伤兵/2)`，减去建筑保留需求。因此，**通过475250的内嵌驻军分支可能再贡献半额**；这与重制只从`World.Units`的非内嵌／非人员军事队伍取账本输入不同。

原作完整公式应表达为：建筑现兵与半数伤兵减保留需求，再加“合格通用单位”的累计；该累计按51目的地全额、其他非40～43按当前地域（内嵌取关联建筑）半额分别归属。此前既把通用表缩成野战表，又把`462740`一概称作服务建筑，均需更正。这里只确认通过资格的内嵌分支，不声称所有驻军在自然运行时必然重复计入：mask2等标志的全部初始化／生命周期尚未穷举。

因此，上表“服务城3／当前城1”的2000野战队在原作静态条件下应向城1贡献1000，而“服务城1／当前城3”向城3贡献1000；当前恰按服务据点作相反归属。不据此将原作最终预算定为9000或10000，因为尚需计入对应合格内嵌驻军等通用对象。这是原作记账分支的静态差异；本轮只实测当前实现，没有原游戏实测。

现行B25明确规定其他军事队伍半数兵伤计入**服务据点**，当前`TransportBudget`确实沿用该规则，且仅遍历现代独立野战单位。需要同时修正原作研究事实、明确是否保留这些重制选择；未经用户裁决，不直接改B25／产品，也不把它简单称作当前遗漏条件。本报告不外推到其他自动工作的对象域或记账方式。
