# 原版与重制版旬初性能对照

`EXP-ORIGINAL-TURN-PERFORMANCE-20261101`；2026-11-01，Codex。原版完成同档 2 次低干扰基准、2 次阶段采样、2 次逐势力补采；重制版引用既有测量，未重测当前提交。

## 结论

**实验事实，高置信度（本机、各自局面、以下边界）**：原版 33 个自动任务生命周期合计 **230～236 ms**，显式战略／人员准备父入口仅 **14.2～14.4 ms**。重制版历史 Release 预热均值 **242.68 ms**、中位数 **245.24 ms**，与原版完整 AI 任务同量级；两者不是同一世界状态，且原版计时含内部调度等待，**不能据此认定谁更快或给出算法倍率**。

原版确认到日模拟入口为 **477～482 ms**；约 246 ms 的额外时间几乎都在 AI 开始前。调用链存在目标时长 200 ms 的侧栏收起动画，推断它是主要来源，尚未单独动态计时。此前约 11 ms 只代表 work62，每日约 7.6～7.8 ms 也只是所选入口的局部均值，均不能代替完整非界面成本。

## 复现与验证

仓库根目录运行，使用全新忽略目录，三种模式顺序采集，不能同时附加同一进程：

```powershell
python -X utf8 research/experiments/original-turn-performance/capture.py --mode opening --output local/generated/research/original-turn-performance/new-opening-session
```

`boundary` 只采外边界／日期，`detail` 增加 16 个原生入口，`opening` 再采低频准备和生命周期。出现 `COLLECTOR_READY_UNARMED` 后手工读档，向会话 `control.json` 写入 `{"action":"arm","label":"baseline-1"}`，再确认进行；下一轮先重读同档再 arm。写入 `{"action":"stop"}` 会等活动旬结束后脱离会话并卸载探针，`abort` 只标记当前旬无效。采集器拒绝已有输出目录；`--self-test` 可在独立进程检查原生嵌套采集。

本地证据根为 `local/generated/research/original-turn-performance/`：`boundary-20261101-01/`、`detail-20261101-01/`、`opening-20261101-01/` 保留逐轮 JSON、事件、代理副本及指纹，另有环境／模块、私有输入副本和手工存档前后指纹。离线复算：

```powershell
$captureRoot = 'local/generated/research/original-turn-performance'
python -X utf8 research/experiments/original-turn-performance/summarize.py "$captureRoot/boundary-20261101-01" "$captureRoot/detail-20261101-01" "$captureRoot/opening-20261101-01" --output "$captureRoot/report.json"
```

统一汇总器在 `report.json` 的 `modes` 输出各采样模式分布，`opening` 输出逐势力归属及两次明细；姓名仅在离线汇总解码。六轮日期码均为 `54570 → 54580`、十天连续、完成为真、计时栈无溢出或截断；补采另核对每军团各一次 work62／work22／父入口、生命周期归属及进入日模拟时 33 任务全部结束。脚本收敛后六轮统计与原产物完全一致，独立进程原生自检、停止请求等待、安装失败脱离及已有目录拒绝检查通过；未重新采样原游戏。原始采集校准约 0.231～0.270 微秒／原生调用，不代表实际或 JavaScript 探针开销，未机械扣除。其他线程不计入 CPU 项；原生排除时间仅排除已探测子入口，不是完整业务独占成本。

采集结束卸载探针，恢复原手工档，32 个手工存档 SHA-256 不变；自动档按游戏设置轮换并保留试采后副本。排除的试采命中高频轮询 `0x50A760` 6,741,124 次，正式版移除该探针；试采漏加纪年基准 130（151 应为 281），原始日期码正确，日志未重写，正式版依据 [RE-0041](../../findings/RE-SAN9PK-0041.md) 修正。姓名原始字节始终保留，离线按已有[私有字映射](../../../tools/font-s9-generator/generate_font_s9.py)还原 `FA40` 等六字。
