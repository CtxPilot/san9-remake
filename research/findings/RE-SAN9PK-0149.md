## 阅读约定与结论

**事实。** 培养依次经过候选建立、等待激活、选择导师与方针、旬推进、事件与成长、正式出师；途中可以换导师、延长、暂离、返回或永久中止。无干预时有九次倒计时递减、四次常规成长；教学事件另有能力与熟练度奖励。

| 符号／术语 | 含义 |
| --- | --- |
| `R(N)` | 培养处理器的定种随机整数，范围 `0..N-1`；不表示每次在统计上独立 |
| `G(N)` | 全局随机流整数，范围 `0..N-1` |
| `P(q)` | 比较 `R(100)<q`；`q<=0` 不成功，`q>=100` 必成功 |
| `div` | 有符号整数除法，向零截断；非负数时等于向下取整 |
| `isqrt` | 整数平方根，不是平方 |
| 基础／当前能力 | 两组字段；当前能力由伤势、宝物、官爵等派生，不能互换 |
| `C/E/H` | 倒计时、教学评价 `0..4`、非零事件史数量 `0..3` |
| `d(A,B)` | 原版人物相性距离：150 点环距再截断到 50，范围 `0..50` |
| 改善评价 | `2→1、3→2、4→3`，`0/1` 不变 |
| 恶化评价 | `0→1、1→2、2→3`，`3/4` 不变 |

评价越小通常越有利，但不是年龄、培养进度、旬号或一般好感。普通改善不能把 1 推到 0，恶化不能把 3 推到 4；极端值由专门事件直接设置。

本轮纠正的关键事实：

- 能力倍率由**学生性格 × 方针 × 评价**选表，同一表用于全部常规节点；旧稿“按四轮换表”错误。
- 事件 `15..22` 会改善或恶化评价，旧稿“只显示消息”错误。
- `+0x70` 是义理，`+0x74` 是野心；返回参数和事件 19 资格不是未知字段／内部进度。
- 事件 `9/12` 另有结果判定，命中不等于一定暂停。
- 初始兵法和事件 26 存在入口条件与实际读取／结果池不同的边界。
- 随机计数器属于临时处理器，**不属于持久培养记录**；触发时及势力处理时重新构造。

## 状态所有权、容量与保存

### 持久记录

**事实。** 有八项培养记录，运行时步长 `0x148=328` 字节，继承人物数据并附加培养字段；328 是内存步长，不是每项存档字节数。保存／读取逐项序列化人物、以下扩展及保留区。

| 内存偏移 | 大小 | 语义 |
| --- | ---: | --- |
| `+0x128` | 4 | 当前介绍人／发现者引用 |
| `+0x12C` | 4 | 导师引用，无引用为 `0xFFFF` |
| `+0x130` | 4 | 触发人物引用，部分引用修复路径可重写 |
| `+0x134..137` | 各 1 | 生成时基础能力快照，顺序统、武、智、政 |
| `+0x138..13B` | 各 1 | 四项培养上限 |
| `+0x13C` | 1 | 方针：0 均衡、1 严格、2 躬亲 |
| `+0x13D` | 1 | 教学评价 `E` |
| `+0x13E` | 1 | 倒计时 `C` |
| `+0x13F` | 1 | bit 0 已延长；bit 1 暂离／暂停 |
| `+0x140..142` | 各 1 | 三项事件史，0 为空 |
| `+0x143` | 1 | 触发码 |
| `+0x144` | 1 | 阶段：0 等待、1 培养中、2 完成待转换 |
| `+0x145` | 1 | 培养所属势力记录号 |

空闲另由人物空状态判定；阶段 0 同样存在于重置记录，不能单看它判断候选存在。每势力最多匹配一项有效记录。事件史写第一个空位，满后不变；不是全部事件都会记史，也不是发生三件事后所有事件停止。

### 两个容量口径

正式培养人物使用 `800..849` 五十槽，头像用 `786..835` 五十编号，与自创人物 `700..799` 分开。

- **建立／重建**：全部非空培养记录（包括等待）加已占用正式培养槽，须 `<50`。
- **激活**：只统计非等待的非空记录，加已占用正式培养槽，须 `<50`；等待者不计入。
- 头像另检查正式培养人物及八项非空记录，重抽已用编号。创建还须有可复用等待记录或空闲记录。

因此已有等待者可在包含等待者的总和为 50 时激活。创建先查容量才复用等待记录，满额时也不能认为重建必定允许。正式槽占用按人物是否为空判断，不等于仍为本势力效力的人数。

### 引用修复与终止

旬处理先遍历记录核对势力及导师／归属对象。培养势力失效或不再满足玩家势力检查时，可显示失踪消息并重置；归属对象改变时跟随有效导师所在对象，导师不可用时尝试君主所在对象，不是投奔导师的新势力。

导师仍可解析、未暂停，且身份为死亡 8、俘虏 4 或所属势力不符时，清导师引用，从本势力有效非俘虏人物重选导师及方针。初始与失效重选允许君主；事件 6/8 另排除君主与原导师。失效函数以“导师引用可解析”为外门，不能宣称任何损坏引用都自动修复。

介绍人、导师、触发者是三条引用。介绍人仍属培养势力时沿用；不符时，替代搜索虽然按学生最高能力分支，却仍比较学生自身的相同能力字段，不能由此选出更强介绍人。后备搜索实际保留首个有效同势力、非君主、非俘虏人物，无合适对象再取君主，并可能同时重写触发引用。不能称为自动选取最强武将；初始生成和激活时的引用刷新也不能混为重掷初值。

## 触发与激活

### 实际入口

**事实。** 完整静态创建调用点如下。模式 2/9 跳过创建、激活及旬处理，玩家界面名称不由本记录猜定。

| 码 | 实际入口 | 限制 |
| --- | --- | --- |
| 1 | 部队战败收尾，旧军团／势力记录在解散检查后失效，由胜方对象尝试创建 | 并非每次击败部队，也未额外要求根势力彻底灭亡，不能笼统写“消灭任意势力” |
| 2 | 城市占领的城市分支 | 目标须通过当时有效所属检查；普通设施不走此分支 |
| 3 | 捕获人物成功后的捕获方对象 | 所属对象与玩家控制资格有效 |
| 4..15 | 武系兵法 0..11 的**双动画／加倍判定成功分支**，码为编号加 4 | 施放人物的玩家势力门成立；普通发动或出现动画不能替代 |

对象入口先找有效负责人，必要时回退成员选择，解析所属及玩家控制资格后进入创建。兵法入口直接用施放人物。“玩家所属／直接军团控制”不是画面可见性谓词。

没有建设完成创建入口；谋略、策略、水军等也不能泛化为确认触发。第三方电子书“建设完成”“任意兵法”不作为本样本事实。

本势力无记录或仍等待时，合格触发可以重建整个人物，替换触发者、码、身份、初值、上限、兵法及人格；不累计多名候选。已进入培养或完成后不再重建。

### 激活

资格：有效君主与等待记录；剧本已过至少 10 日；当月日数不大于 10；通过激活容量门；有至少一名本势力有效非俘虏人物；记录未有导师，触发码非零，触发引用未置无引用。概率通过后还要解析并刷新介绍人，才进入选择界面。

```text
q = max(10*(10-N_generated)-N_persons,10)
激活：R(100)<q
```

`N_generated` 是**当前有效且仍属该势力的正式培养人物数**，不是历史毕业总数。`N_persons` 来自同根势力人物查询，不是驻留人数或导师名单长度。例：前者为 0、后者 20 时阈值 80；3、20 时为 50；最低 10。

失败保留等待记录。是在合格势力行动入口尝试，不能仅凭日期门称“上旬每天一次”。激活置阶段 1，选择导师／方针，`C=9`；均衡、严格初始化 `E=1`，躬亲 `E=2`。换导师也重写评价，但不重置倒计时。

## 初始人物

### 身份、姓名与年龄

**事实。** 随机选未占用头像 786..835；组内 0..34 男，35..49 女，年龄为：

| 组内序号 | 年龄 |
| --- | --- |
| 0..4、35..36 | 15..17 |
| 5..9、37..40 | 18..20 |
| 10..21、41..44 | 21..24 |
| 22..31、45..48 | 25..29 |
| 32..34 | 30..32 |
| 49 | 固定 30 |

出生年为 `当前年+1-年龄`，总范围 15..32。姓名由 104 姓、男性 444 名／女性 31 名组合，拒绝重名及源字符串长度不在 1..10 的结果；源字符串单位不是重制姓名上限。姓索引通过并行表写旗号，语义已由 RE-0009 核查，不能继续称未知字段。

寿命档为 `2+R(6)`，即 2..7，不是剩余年数。头像、姓名、年龄用全局随机；寿命档用培养处理器随机。

### 基础能力与上限

令 `T_i` 为触发人物对应**基础能力**：

```text
统率 = 35+R((T_统-50) div 3+20)
武力 = 35+R((T_武-50) div 3+20)
智力 = 30+R((T_智-50) div 3+25)
政治 = 30+R((T_政-50) div 3+25)
cap_i = min(70+max(0,(T_i-74) div 6)+R(30),100)
```

按统、武、智、政交错生成各项初值及上限，初值另存快照，不能重排八次随机调用。触发者统率 50／80／100 时初值分别 35..54／35..64／35..70。触发能力 100 时上限为 `min(74+R(30),100)`，不是在 74..100 均匀抽取。

### 人格

- 相性：80% 为所属君主相性 `-R(21)+10`，按 150 环归一化；20% 为 `R(150)`。
- 义理：50% 为 `clamp(触发人物义理-R(5)+2,0,15)`，否则 `R(16)`。
- 野心：同上，参照触发人物野心。
- 性格：50% 继承触发人物性格，否则 `R(4)`。

相性参照君主，其余参照触发者；均使用培养处理器随机。

### 初始兵法与缓存边界

**事实。** 强制兵法读取 `L=学生当前统率+当前智力`，不是刚写的基础能力：

| 触发码 | 强制写入 |
| --- | --- |
| 1/3 | 无 |
| 2 | `P(30)` 时给 19 营造 |
| 4 | 0 奋战 |
| 5/6 | 0；`L>=120` 再给 1 奋斗 |
| 7 | 3 突破 |
| 8 | 3；`L>=120` 再给 4 突进 |
| 9 | 3；`L>=120` 给 4；`L>=150` 给 5 突击 |
| 10 | 6 骑射 |
| 11 | 6；`L>=120` 再给 7 奔射 |
| 12 | 6；`L>=120` 给 7；`L>=150` 给 8 飞射 |
| 13 | 9 齐射 |
| 14 | 9；`L>=120` 再给 10 连射 |
| 15 | 9；`L>=120` 给 10；`L>=150` 给 11 连弩 |

码 6 的 `L>=150` 分支仍重复写 1，没有写 2 奋迅。

再按 0..30 顺序，对未学且不在 `{0,3,6,9,12,16,20,24,27,28}` 中的项逐项投骰：触发者会时阈值 `min(50,学生当前智力)`，不会时为 10。

**缓存事实与限制。** 初始化先写基础能力，再生成兵法，末尾才统一重算当前能力。基础 setter 不刷新当前值；记录重置也未直接清除四个当前能力缓存。因此必须读**调用当时缓存**，不能将本次新生基础值代入 `L` 或智力概率。等待重建、槽复用、加载初始化对缓存初值的实际影响，本轮未动态对照；不宣称所有新候选固定为某缓存值，也不据此宣称高阶分支普遍可达。仅给四项新生基础值不足以预测初始兵法。

### 熟练度与精通

按已学兵法 0..38，给对应类别加 `兵法门槛 div 3+R(50)`，上限 1000；授予本身仅覆盖 0..30，不是自动得到额外兵法。已有任一兵法的类别置精通，再追加：

```text
武系抽取次数 = min(5,(基础武力+基础统率-100) div 20+2)
谋略抽取次数 = min(3,(基础智力+基础政治-80) div 20)
```

次数不大于零时不抽；分别从 0..5、6..8 抽精通位，允许重复，次数不等于不同精通数。

## 逐旬顺序与成长

### 时间线

**事实。** 势力入口构造处理器，依次“递减 → 激活 → 处理活动者”。刚激活时本次仍为 9，下次才递减到 8。

活动处理：同步归属；尝试暂离者返回；仍暂停者另判永久失踪；必要时修复导师；未被返回／重选等阻断时，依次尝试特殊、教学、普通事件；最后读取**事件后**倒计时及暂停位，结算成长、中段报告、完成和正式转换。

| 递减次数 | C | 无干预节点 |
| ---: | ---: | --- |
| 1 | 8 | 特殊窗口；常规成长 |
| 2 | 7 | 教学／普通事件 |
| 3 | 6 | 常规成长 |
| 4 | 5 | 特殊窗口；中段报告 |
| 5 | 4 | 常规成长 |
| 6 | 3 | 教学／普通事件 |
| 7 | 2 | 特殊窗口；常规成长 |
| 8 | 1 | 教学／普通事件 |
| 9 | 0 | 仍可先有教学／部分普通事件，再完成 |

九旬、约三个月、四轮是无干预路径。事件 5 把 2 改为 5，跳过当次 2 的成长，随后再走 4、2，净增加一次成长；暂停冻结倒计时，返回旬不补减。中段报告条件为 `C=5`、未暂停、史中无 5，不存在独立已播放标志；延长路径有史 5，不重复该报告。

### 四项能力

导师**基础能力**为 `A_i`、合计 S，学生基础能力 `B_i`、上限 `cap_i`。倍率 M 按**学生性格**选表，再按 E 与方针取列；每格依次 E=0/1/2/3/4：

| 学生性格 | 均衡 | 严格 | 躬亲 |
| --- | --- | --- | --- |
| 莽撞 0 | 150/120/100/80/0 | 160/130/110/90/0 | 150/120/100/80/0 |
| 刚胆 1、冷静 2 | 155/125/105/85/0 | 155/125/105/85/0 | 150/120/100/80/0 |
| 慎重 3 | 150/120/100/80/0 | 155/125/105/85/0 | 155/125/105/85/0 |

```text
K = 3+Σ max(1,A_i div 24)
U = 26-K+max(0,11-K)
V = K+(M*R(U)) div 100
g_i = (A_i*V) div S
```

四项 g 合计不等于 V 时，**四项同时加 1**，不是逐点分余数，最终合计可超过预算。按 `cap_i-B_i` 截断后写基础能力、刷新当前值。E=4 只消除随机部分，仍保留 K，不是完全零成长。非常规编辑产生的零合计输入不由本文保证安全。

### 熟练度

常规成长只写熟练度，不直接调普通兵法习得。导师性格控制类别，学生性格控制上述能力表。

| E | 均衡类别数 | 严格 | 躬亲 |
| ---: | ---: | ---: | ---: |
| 0/1 | 3 | 2 | 4 |

### 选兵法与学习判定

候选分导师会／不会两组。项目 0 或已知组为空时取未知组；未知组为空取已知组。两组均非空，项目 4..14 以师生性格阈值较大者决定是否取未知组：莽撞 20、刚胆 15、冷静 10、慎重 5。项目 1..3 保持已知组路径。

随机选首项后，除项目 5/6/12/14 外，把同类别其他未学项按“导师会的在前，其余在后”加入顺序，不是选四项不相关兵法。

令兵法门槛 t，导师参考 a、学生参考 b：类别 0..5 分别取导师基础统／武较大值、学生当前统／武较大值；6..8 则取智／政。

首项先有**整组成功旁路** `P(max(5,(100-a) div 5))`，命中把该组全部结果写为成功，跳过普通成败门。它不是失败率；不能因老师能力较低使该阈值变大，就反向解读为更容易整组失败。

此旁路的导师同学标志还存在独立不对称：循环只反复写第一个同学标志，最终取决于导师是否会该组最后一项；其他同学标志保持初始化的零。故不能对旁路概括为“老师把所有原本不会的项一起学会”。

旁路未命中时顺序结算，首项惩罚 z=0，后项 10/20/30；项目 2..4 的后项不减此惩罚。

导师会时：

```text
导师门=a+2*isqrt(max(200,导师该类熟练度))-z
学生门=b+max(0,(max(350,学生该类熟练度)-t) div 10)-z
```

导师不会时：

```text
导师门=max(10,a-max(0,(t-max(200,导师该类熟练度)) div 12)-z)
学生门=max(10,b-max(0,(t-max(200,学生该类熟练度)) div 12)-z)
```

两门通过才学会；任一失败停止后项，前面成功保留。导师原不会且双方成功时同学；导师通过、学生失败只显示未完成，不直接给学生奖励。门可超过 100，不另截断。

重复随机助手抽 `max(1,k+1)` 次、返回最后值；导师门 k=项目号，学生门 k=两倍项目号。改变选项会改变内部随机顺序，不是只换显示标签。

## 暂离、返回与永久失踪

**事实。** 暂停不减 C，每次处理依次尝试：

## 随机与存读档边界

**事实。** 处理器 +0xC 为计数器 n，构造置 0；三个对象触发点、一个兵法触发点各在栈上构造；势力入口重新构造后，激活与旬处理共用，结束析构。记录保存不序列化它。

R(N) 按 n mod 4 依次取学生基础统／武／智／政，种子为：

```text
当前日期编码*((max(1,n)+max(0,N)+max(0,所选基础能力)) mod 32767)
```

用模式 0 随机后 n 加 1，不消费普通全局流，但依赖日期、上界、基础能力、调用顺序。

头像、姓名、年龄、常规类别抽取用全局流；初值、上限、人格、寿命、激活、增量、事件与菜单大量用处理器流。消息脚本还可随机措辞，不能据核心模式 0 排除 UI 的全局消费。

可确认外部垫全局骰不直接改变参数完全相同的一次 R(N)，不能确认“SL 一律无效”或“一次触发固定整次培养”。完整预测需当前缓存、入口、短路分支、菜单、全局状态及消息求值顺序；本轮未做跨保存／重入全流程动态对照。

## 普通成长与重制边界

普通成长见 [RE-0131](RE-SAN9PK-0131.md)。培养能力走导师比例分配，熟练度走平方根衰减，教学可直接置兵法位；不能套普通能力 3%、公共精通三倍或普通门槛后学习概率。

研究不提供固定导师排行榜。由事实可推断：导师四维影响预算与分配，导师性格控制类别，导师兵法与当前智力影响教学，学生性格、义理、野心与关系分别参与不同环节；不足以给出脱离学生目标的唯一最优导师。
