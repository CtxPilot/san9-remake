# 2026-10-28 兵法动画全面复核

## 结论与范围

**产品事实。**虎牢关背景错误、飞射声音提前结束、箭岚缺少弹体残影均已定位并修复。另修复同根因的设施编队／武将／数字错位、近远环境声选择、连弩动作与发射错相、跳过补播旧声音，以及亮屏期间单次场景声音未使用渐入增益。

覆盖27项主动／触发兵法：16项武力特写、9项智略／陷阱及2项支援。检查场地与四季、双方对象和身体选择、设施与水军编队、特殊势力、前进／交锋／轮射／移动波次、出箭数量与节拍、路径与残影、局部效果、命中／抵挡／狙击、数字与强化、声音、暂停／快进／跳过及资源退出。领域允许发动的资格不在本次调整范围；扩大身体组合与合成事件用于检验表现消费者，不证明这些组合都能在玩法中发动。

原作证据及实际主库标注见[RE-0192补证](../findings/RE-SAN9PK-0192.md#2026-10-28-关隘场地循环声音与箭岚残影纠正)，不以历史自动化通过替代本次真实对象接线，也不宣称逐帧复刻。

## 发现与处理

| 问题 | 根因及结果 |
| --- | --- |
| 虎牢关使用砦／箭楼背景 | Importer把原作归并类别当成设施目录编号。改为在导入边界统一展开目录引用；所有方向关隘使用墙／关门，砦和箭楼使用堡垒，阵使用普通据点，城塞使用墙。背景、双方兵员、来源武将与目标数字位置共同修正。 |
| 近远环境声与场地不一致 | 原按来源身体猜测，现与背景过渡共用实际占地接触判定；不由兵法名决定。 |
| 连弩回收动作中继续出箭 | 128ms组间脉冲与512ms身体周期各自推进。现把脉冲作为最小间隔，同组在完整周期起点再次发射；支持1～4组回归，不固定三组。 |
| 飞射仍射箭但声音停止 | 移动及射击原是循环通道，重制误排为单次。移动／射击声现在由有限动作区间持有，覆盖最后发射，暂停、静音、跳过和退出按所有权停止；近战前进／交锋的同类错误一并修正。 |
| 箭岚没有箭矢残影 | 模式13的弹体残影分支遗漏，模式11连弩同样遗漏。现保留历史坐标和方向，按原作透明度参数淡出；原箭到达后残影继续有限收尾，不以水纹／身体残影替代。 |
| 跳过后旧攻击声集中响起 | 客户端把到当前时间以前的全部未消费声音补播。现由当日时间线登记跳过边界，消费被略过的声音，保留必要对白和后续正常触发。 |
| 亮屏时单次声音直接全音量 | 兵法只给环境声计算渐入，场景声音增益在切入时直接恢复1。现统一使用入口亮屏的渐入增益，动作循环声另乘自身150ms包络。 |

## 箭流与声音核对

**产品事实；固定表现种子样本。**真实190年包、野战目标下的部分代表性时间线如下，时间从特写动作开始计算；随机位置／延迟可能令其他计划的末次发射时间略有不同。

| 动作 | 投射物数 | 首次／末次发射 | 当前声音与收尾 |
| --- | --- | --- | --- |
| 奔射 | 264 | 0.280／5.945秒 | 移动和射击循环声覆盖0～6秒；等待尾箭到达。 |
| 飞射 | 792 | 0.173／5.033秒 | 射击素材长约2.743秒，现循环至最后发射，不再自然播完即停。 |
| 连弩，野战三组 | 576 | 0.158／4.190秒 | 保留24次组脉冲；同组周期512ms，最小组间隔128ms，带弹体残影。 |
| 箭岚，楼船对楼船 | 288 | 1.505／5.095秒 | 四轮、12次成员射击，保留分轮攻击声；新增逐帧弹体残影，反馈等待其淡出。 |

连射仍保留分轮箭簇；移动波次按自身位置和交替发射点出箭。没有把所有兵法改成连续箭雨，也没有按残影副本增加真正投射物数量或伤害。近战、齐射、移动波次、命中／抵挡、局部火焰、强化与数字的声音分别持有触发／持续区间；重复绘制不分配新声音。

## 再次追查剩余分支

**结果。**上一轮的组合采样没有覆盖全部局部创建机会与真实前景顺序，继续逐项追查后又发现五类遗漏，现均已修复：

| 遗漏 | 修复与独有证据 |
| --- | --- |
| 楼船强攻缺随机水花 | 补齐12次75%矩形散布尝试和两种运动方向；三处固定闪光继续保留，奋战的11处固定闪光独立。Importer核对声明，Rendering验证坐标范围、运动样式和稳定采样，Godot加载实际楼船强攻。 |
| 部分船体交锋烟雾少一次机会 | 身体14／16恢复两次独立50%机会，到达只生成一次必出烟雾；避免把两者混为重复喷烟。 |
| 堡垒前景被兵员盖住 | 前景构件从静态底图拆为明确的Foreground层，排在兵员后、命中／数字前；Godot以临时内存中的砦类型测试来源／目标两侧，未改用户场景或存档。 |
| 长受损反馈漏附加声音 | 成功反馈超过1秒才安排一次附加声，短反馈和抵挡不播，不增加等待；真实客户端检查触发与重复采样去重。 |
| 狙击／强化全屏图被局部显示覆盖 | 全屏精灵位于兵员、前景及数字之上，转场遮罩与必要对白仍在其上；Godot核对实际层级并保留截图。 |

原作与产品证据分列于[RE-0192追加](../findings/RE-SAN9PK-0192.md#2026-10-28-剩余局部效果前景与受损声音分支复核)。本次逐分支复核还检查了16种武力动作入口、全部身体资源分派、三类设施场景、地形族和季节／边缘／接触过渡、移动与射击、受损／抵挡／收尾，以及27项主动表现的效果／全屏归属；未发现其他可确认的整段缺失。此前已通过且输入未变的数字、人物身份、普通地图效果、暂停和快进覆盖继续复用，不将其计作新的原作动态验收。
