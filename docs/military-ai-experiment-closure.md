## 结论

当前失败由实现缺口与计划可执行性不足共同造成。可从代码和验证范围确认的问题包括：

| 层面 | 结论 |
| --- | --- |
| 基本行动评价 | 固定据点价值扣减成本不能替代任务可完成性、实际战力、预计损失与来源生存判断；继续调整常数不足以解决模型缺失 |
| 联合规划 | 逐军团单队提交后追加支援，不等同于出发前组织多城合攻；共享批次与承诺结构没有自动形成联合决策 |
| 规则与态势 | 目标兵法适用性、空据点成功条件、邻城动员、最后城市生存及实际 ETA 的使用曾遗漏或未闭合；部分已有局部修正，完整行为仍未验收 |
| 验证 | 公共命令接通、保存恢复与受控局部测试不能证明实际战争取舍合理；预置主攻队的支援测试不能证明从零发现合攻 |
| 计划 | 范围宽、模块和验收描述多，但最小规则基准、关键规则清单、决策顺序及具有区分力的验收样例不够具体，未有效约束临时评分与阶段扩张 |

提前切换实验入口有后续授权，不作为擅自违反原切换安排的证据。问题在于能力和验收尚未成立；最新阶段记录已纠正为 M1～M3未完成，M4／M5也未达到出口。M0的成本和基础设施实验保留其有限结论，不代表完整策略成功。

现有证据不足以将整体失败归因为性能超限，也不足以断言交通网、索引或战役组织方向本身不可行。未根据实现结果推断执行者动机。
