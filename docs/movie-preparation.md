# 电影准备与接入

电影采用独立的可选共享资源库，不参与剧本世界数据和存档。内容根目录的`shared/movies/catalog.json`使用schema1，以`movies`字典声明语义角色到根目录相对`.ogv`路径的映射。自制内容可使用自己的文件名；声明的资源必须存在且具有Ogg Theora头，路径不得逃出内容根目录。未安装资源表表示没有电影库；未声明的角色继续后续剧情，已声明但缺失或格式错误的资源拒绝加载。

剧本在自己的`presentation.json`中用可选字段`openingMovie`显式引用电影角色，例如`"openingMovie": "scenario-opening-4"`。未配置或为null时不播放开场；客户端不根据剧本ID、日期或分类推导引用。任意剧本可引用同一角色，也可单独更换或取消影片，改剧本ID不改变已有引用。电影资源表仍只负责角色到文件路径的映射，同一文件可供多个角色引用。

TC101 Importer负责把原版剧本0～19的h／v视频对应关系写入各剧本表现数据；`scenario-opening-0`～`scenario-opening-19`只是本批资源命名，不是通用客户端约定。修改某个剧本的开场只需编辑该剧本的`openingMovie`；新增或更换物理视频时才更新电影资源表及文件。

当前采用原分辨率640×480、30 fps、Theora Q4与立体声Vorbis Q5。导出只做轻度去块、时空降噪和微量锐化，不做AI修复或预先放大；客户端以视频固有尺寸作为逻辑尺寸居中显示，随整个游戏界面一起缩放，不单独拉伸至铺满窗口；视口不足时等比缩小，使用线性过滤。

## 显式转换与发布

电影转换只在显式执行`import-movies`时发生，使用用户环境PATH中的`ffmpeg`，不下载或捆绑编码器。找不到时打印跳过原因并正常返回，不修改已有电影及资源表；已找到但运行失败、缺少编码器或转换失败则报错，不伪装成跳过。普通`import-content`、`import-client`及其局部重建均不转换或复制BGM、音效和视频。

```powershell
dotnet run --project src/San9.Tools -- import-movies --game-dir "C:/home/game/san9/San9 Tc" --output local/generated/content --group all
```

分组为`events`（Event00～13，共14段）、`scenarios`（20段开场）、`startup`（theme与op_pk，不含logo）或默认`all`。命令直接读取原版游戏目录中的`MOVIE/*.mpg`，输出到最终内容包`shared/movies/<语义角色>.ogv`并更新电影资源表，保留其他已有绑定；不重导世界或纹理。客户端只读取最终内容包，不依赖原版或独立的已准备视频目录。

固定使用原尺寸、Theora Q4、Vorbis Q5与以下轻度修复滤镜：

```text
deblock=filter=weak:block=8:alpha=0.05:beta=0.025:gamma=0.025:delta=0.025,hqdn3d=1.0:0.75:1.5:1.0,unsharp=5:5:0.25:5:5:0,tpad=stop=-1:stop_mode=clone
```

`asetpts=N/SR/TB`按解码采样数重建音频时间戳；`tpad`仅在视频尾部不足时保持最后一帧，`-shortest`按音轨结束截断，不改变中途节奏。保留44.1kHz双声道、Theora关键帧间隔64及yuv420p，不做AI修复或导出放大。原版解码存在的缺陷与转换输出损坏分别处理；每个输出均通过严格完整解码后才替换目标文件。

`shared/media-conversion.json`记录源内容、编码参数和最终输出的SHA-256，用于复用未变化且完整的产物；任一依赖变化或输出缺失／损坏只重转对应文件。无转换记录的已有文件无法证明依赖一致，首次显式执行该组时会重新转换。转换临时文件位于最终目标旁，成功、失败或取消均清理；只保留最终视频、电影资源表及转换记录，不保留中间视频副本和实验目录。生成物与原版素材均不提交。

## 播放与手动验收

电影开关关闭时不播放，也不读取电影目录或校验电影文件；加载剧本内容包不加载电影库。启动与剧本开场仅在开启电影时读取电影库；局内在首次实际播放请求时加载并校验电影库，由当前会话保留目录供后续请求使用。局内重新开启电影后，下次播放请求按需加载，不补播已跳过的电影；已声明但缺失或格式错误的资源在加载电影库时拒绝。电影音轨随音效开关。播放请求显式指定外围模式：事件电影保留原游戏画面，当前引入对白在电影期间隐藏；剧本开场、结局等其他电影使用全窗黑色背景。两种模式都以视频固有尺寸作为逻辑尺寸居中显示，跟随整体界面缩放，视口不足时等比缩小。外围保留游戏画面不开放底层交互：播放期间仍暂停现有背景音乐及其淡出计时，阻止底层下令、剧情续行和地图演出。播放自然结束、点击、空格／Enter／Esc跳过后继续原叙述并恢复仍有效的音乐；取消或退出会话释放播放器、输入锁和音乐暂停所有权，不重算事件效果。

正常启动先按`startup-theme → startup-opening → 主菜单`顺序播放；不接入厂商logo，不加载地图。两段分别支持跳过，结束后进入主菜单；同一进程返回主菜单、新开局和读档不重播。显式指定剧本／内容包直进游戏及独立编辑器入口绕过这两段，仍各自遵守既有剧本开场规则。关闭电影开关或未安装对应角色时继续下一步。

新游戏先播放所选剧本电影，视频首帧显示后在后台准备地图和游戏资源；地图保持隐藏，新场景音乐保持暂停。影片结束或跳过后，地图未就绪时继续黑屏等待；地图先就绪时等待影片完成，双方就绪后淡入地图，再播放“战略”字图、军师开局发言和初始事件。影片和加载等待期间不推进字图计时、日期或玩家命令；多人轮流控制同一局只播放一次，读档和控制交接不重播。关闭电影开关或未安装该角色时立即继续开局；后续重新开启开关不补播已完成的开场。自定义武将和势力部署不改变当前剧本对应的影片。

207年剧本使用刘备势力、史实模式，完成徐庶推荐后，让刘备亲自探索隆中；首次拜访和再次拜访分别播放两段视频，资格与归队规则仍遵从[三顾之礼](../specs/behavior/BEH-EVENT-0002-event-selection-and-commit.md#三顾之礼完整链)。画面、声音及真实剧情交互由本次任务的用户手动验收。
