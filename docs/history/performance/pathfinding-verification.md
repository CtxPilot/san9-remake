# 导航历史对照与回归摘要

以下为2026-09～10所标版本的历史结果，不是当前实现、协议或性能承诺。现行规则见[导航设计](../../../specs/navigation-redesign.md)，当前旬推进见[性能记录](../../ai-performance-records.md)。同一指标只保留对照条件、结果和适用边界；逐轮修复、测试数量增长和失效格式迁移由Git追溯。

## 测量口径

完整会话包含AI、行军、战斗、经济与收尾；独立navigation关闭战斗／外交／AI、所有设施及其他队伍硬挡、固定10细单位接近范围。二者不可混算。累计线程分配不是峰值或驻留内存，GC后新增保留也不是进程总内存。

历史工具的设施矩形曾未按地理倍率展开；500队等压力输入会激活部分非仕官人物，属于合成初态。除明确标注逐事件相等的纯优化外，换算法、前瞻、占地、减速和随机会改变战局，耗时差不是等价工作量的算法加速。没有原作逐日动态或Godot画面／听感验收。
