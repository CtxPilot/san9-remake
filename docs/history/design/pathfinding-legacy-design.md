# 旧粗格A*导航取舍摘要

历史基线：`c92204c49db595e56a652ec957f71ac815e42ca3`（规则v139）。旧实现已被[粗细两级导航](../../../specs/navigation-redesign.md)替代，以下不作为当前算法或兼容要求。

## 旧模型与替换原因

全局搜索四邻粗格中心，起终点在3×3粗格窗口接驳，实际粗边逐细步检查完整占地；固定占地不随兵力变化。200×200粗图将工作区限制在4万节点，有意接受漏掉窄通路，不提供全图细搜索兜底或扩窗重试。

费用分为地形和非负避让，实际移动只扣地形时间并保存余量；同价使用固定顺序，没有原作的连线走廊折扣或局部随机。每日重规划只持久化前瞻点与真实目标几何，前瞻失效后重搜粗图；不保存全程路线。

路线页冻结外部世界并逐日重演，精细ETA复用真实移动；AI粗估只进行一次战略搜索。后两者承诺不同，不能用粗估证明完整占地通行，也不能用冻结预测保证实战到达日期。路线页和ETA重复放大每日搜索成本，是替换时的重要代价。

旧方案状态少、实际边检查严格、结果可复现，但粗中心图不完备、端点成本高、预览过重，也不能表达原作的兵力占地与局部导航。A*本身不证明连续空间全局最短或实战更少卡住。

## 保留的工程教训

- 分离择路偏好、实际行军时间和查询预算；分别报告地形无路、动态等待和计算未完成。
- 内部阶段点不能覆盖真实到达条件；途中到达、阶段失效和目标变化均须重新判断。
- 搜索工作区可复用，动态位置、外交和占用引用必须按查询失效；不把旧搜索器作为隐藏回退。
- 比较独立导航、完整会话与路线质量，不用提前等待或减少成功结果冒充等价提速。

新旧测量见[历史导航性能](../performance/pathfinding-verification.md)。精确旧实现从上述提交的`BattlefieldPathSearch.cs`、`BattlefieldMap.cs`、`MovementOccupancy.cs`和`MilitaryRouteQueryContext.cs`追溯，不在文档复制旧算法细节。
