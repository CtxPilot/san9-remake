HOW TO READ

只看地图与关系。

选择剧本仅用于确定建筑配置。城市、港口、关隘及已建设施来自转换后的地图建筑表；没有建筑的地域不作为网络节点。

设施连线由静态地形求路和参考行程决定，不要求地域接壤，也不依赖所属城市。只要参考行程不超过滑块上限就连线；没有近邻数量或总边数截断。白线是关系示意，不是实际路径轨迹。

城市归属直接使用地域所属城市引用。辖区颜色仅区分城市，选中城市时高亮其辖区。工具不提取或展示势力、控制权、兵力、武将和AI决策。

参考移动条件：井阑＋楼船，机动力读取内容包（当前分别为45、50）。四向粗格Dijkstra求路，每粗格5细单位，累加地形通行代价÷对应机动力；最大预计算65日。未计入阵形通行净空、建筑出口、物体避让、交战、停留和外交阻挡，不替代Core正式出征估时。途经或临近其他设施不删边；是否适合进攻需由游戏AI另行评价。
