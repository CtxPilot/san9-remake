# 原版 AI 策略扩展取舍

本页保留2026-10-31已明确的拒绝、暂缓和放弃决定，以及理由与后续考虑方向。这些方向尚未采用，不列为当前待办。当前采用规则见[行为规格](behavior.md)。

<a id="attack-planning-decision-20261031"></a>
**进攻范围与批次动员试验已撤回（用户确认）。**本轮撤回为解决白马港不出兵而增加的来源向目标范围、直接地域邻接放行、沿路改选后的扩展来源重建，以及普通攻击／请求履约的真实队伍批次预编。产品代码恢复已提交基线，专用试验测试移除；原试验B31未进入采用规则。已提交的B20后续目标尝试、战略敌对资格、工作内查询复用及独立修复集继续保留；Core现有公共出征准备及单条AI命令复用也保持，不回退已提交接口。试验撤回时的基线为`san9-core-g10-v207`；协议和内容未变化。

**原因与证据边界。**白马港在沿路改选目标后被来源重建筛掉的事实及原作受控复验仍成立，见[白马港研究](../../research/topics/ai/military.md#baima-idle-20261029)。用户反馈试验还使电脑向较远设施出兵；实现确实把来源与目标同属城、来源属城的军事邻城包含目标属城、直接地域邻接并列作为范围入口，较原先的目标侧来源收集扩大了设施来源组合。该范围没有单独裁决具体据点间的出兵距离与战略价值；本轮没有穷举远设施局面，不把用户反馈外推为所有远设施必定出兵。

试验同时把来源修复与批次选人、阵形费用、人物／兵力／出发占用预留及提交复用耦合。履约在首队已经足够时，仍可能提前为最终不提交的第二队抽样选人和兵法，改变既有短路抽样顺序。定向测试和阶段性能记录不能证明这些策略变化的整体收益，因此本轮整体撤回，停止追加局部筛选条件。

**后续方向，尚未采用。**后续统一设计战略目标、前沿来源与具体队伍出发条件，明确静态军事邻城、地域接壤、实际路线／行程各自的职责，再综合守备风险、在途承诺及兵力／人员成本；Core持有公共命令资格与资源结算，Application组织策略。未来验收同时覆盖白马港近处合法机会、沿路改选保留合理来源、远设施进攻约束，以及履约成功／拒绝的随机消费与资源反馈。白马港来源重建问题仍待后续统一方案解决；以上为设计方向，尚未采用。

<a id="transport-demand-decision-20261031"></a>
**需求驱动输送扩展暂缓（2026-10-31用户确认）。**撤回按据点需求、余兵和缺口取代前后方分组的整项未提交改造，包含前线余兵输出、受攻击据点优先接收、按缺口多来源补足及进攻集兵需求；恢复已提交版的输送分组和预算，保留满兵、伤兵与在途容量保护。该方向可以调动受旧分组限制的兵力，但尚不能据此证明整体战局或守城效果更好；进攻需求可能重新锁住兵力，补防优先未判断送达时效，零碎输送会占用人物，计算及分配成本也明显增加。本轮不单独保留守备缺口试验方案，不新增异族补防例外。后续如重做输送，应统一考虑战略集兵目标、守备风险、援兵送达时间、在途承诺和输送运量／人员成本；当前不列为必须实现或验收的要求。原作研究事实不变。

<a id="attack-strength-decision-20261031"></a>
**实际出征兵量优势约束暂缓（2026-10-31用户确认）。**撤回将来源可用兵估值截小为实际批次兵量，以及将行动收敛组70000概率后备门改用批次兵量的限制，恢复按来源驻军的既有判定；不为异民族另加优势豁免。把针对据点总兵力的比例门直接套到单次出征兵量，会统一收紧进攻资格，可能压制人物有限但驻军很多的异民族等激进势力。实际出兵未满足旧比例，不足以证明该次进攻无效或必败。后续将实际战力估计与风险接受策略分离，由势力倾向和进攻目的共同决定出兵条件，当前不将该设计列为必须实现或验收的要求。原作流程及原始诊断事实不变。

<a id="defensive-eligibility-decision-20261031"></a>
**防御判定调整不采用（2026-10-31用户确认）。**本轮撤回以实际攻城命令替代迎敌敌对资格、将异族建设队排除出拦截候选，以及给防御压力额外增加己方部队排除条件这三项未提交调整，保留`d58eae51`的现有判定。需求驱动输送扩展另已撤回，不以输送新增友好势力来袭的响应资格。原作迎敌已读取有效目标并检查势力敌对资格，读取命令本身不是本轮新增能力；本决定不修改已有的信息读取方式。

后续优化可考虑的场景：**甲乙关系友好，但乙的一支部队仍接到了攻打甲城池的命令。**是否响应、何时响应，应在后续优化中结合外交关系与旧命令的处理统一评估；当前不采用新的响应规则，也不将此场景列为本轮必须修复或验收的缺陷。

<a id="office-ranking-decision-20261031"></a>
**任官评价改造暂缓（2026-10-31用户确认）。**为暂时减少偏离原作的程度，本轮不合并现职能力去加成、取消忠诚排序奖励及按无伤能力任官的改造。保留`d58eae51`已提交的占职及候选消费修复，当前任官继续使用原作的有效能力和忠诚加分规则。单独改变评价分数会联动文武官的人选分配，减少换职不等于整体任用更优；后续优化官职任命规则时，再统一考虑文官、武官分别安排哪些武将，以及评价口径、资格与分配顺序。该优化尚未采用，不作为本轮实现或验收要求；原作事实与既有诊断不变。

<a id="corps-replanning-decision-20261031"></a>
**军团重规划扩展已放弃（2026-10-31用户确认）。**保留`d58eae51`已提交的稳定性修复；不采用每轮计算完整目标区域方案、现任都督排序优先及按目标差异拆建军团。既有修复已覆盖反复拆建的主要问题，完整重规划尚无明确战役收益，却会扰动辖区、都督及钱粮分配；评估中还复现了已达上限的有效军团因都督正常出征而被解散重建。此项扩展的实现及对应验收调整已撤回，不作为后续待实现要求；原作研究事实不变。
