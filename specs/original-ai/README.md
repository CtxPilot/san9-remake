# 原版 AI 新规格

## 状态

当前生产采用原版决策基线，OAI-00～05已完成接线与对应阶段出口；OAI-06原作对照、完整内容及十年全图验收尚未完成，完整基线未交付。阶段划分与出口见[实施计划](implementation-plan.md#阶段顺序与交付出口)，历史验证见[性能记录](../../docs/ai-performance-records.md#早期阶段验收)。当前验收保留存档、精确恢复和命令脚本，不要求已撤下的录像。旧自主增强路线仅保留为[归档参考](../archive/autonomous-ai/README.md)。
