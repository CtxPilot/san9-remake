# 旧自主增强 AI 退出摘要

本页保留已退出原型的设计取舍、暂停原因与证据入口。当前生产和验收以[原版AI](../../original-ai/README.md)为准，以下能力目标不自动成为当前或未来要求。

## 暂停范围

2026-10-15，规则v116、保存110／日志114／录像22暂停自主增强路线；随后原版AI接管生产。暂停时AI-01～05完成当时的局部闭环，AI-06统一生产路径仍在收口，AI-07联合规划未通过阶段验收；完整多反应推演、多步对抗及老玩家强度评测均未完成。

原型可以经营、人事、配置、有限外交和军事发令，经公共规则推进到真实占领，并有短局保存恢复验证；这些结果不证明完整战略质量或十年稳定性。AI-07已试验成员／阵形候选、跨队联合比较、作战方向和后方输送，仍可能漏掉互补方案、错误估计补防需求或过度留守。

退出时的主要问题：

- 候选构造、重复比较和临时分配成本过高；总预算未耗尽仍可能被阶段额度截断，工作计数不足以代表实际成本。
- 编队筛选与局部替换不保证联合最优，智略／辅助作用、前锋单挑风险及跨队边际收益尚未闭合。
- 观察续算可能覆盖首轮购粮报价，完整性判断仍读初轮预算；控制范围完成标记可能抑制其他作战方向，训练使整份观察失效。前两项可由当时代码确认，整体行为影响未量化。
- 暂停代码仅构建通过，未在收尾重新运行测试、长程性能或强度评测；不能沿用前版通过结果。

## 原型结构与取舍

原方案使用`Observe → Analyze → Propose → Validate → Submit`：获准只读观察、独立规划随机与确定性额度产生候选，由`SharedAllocator`竞争同一人物和资源，再经公共命令提交。会话持有有限承诺和策略记忆，Core持有真实世界与效果；不允许诊断或墙钟时间影响选择。

AI-03／04的有限经营与军事规则、AI-05外交机会规划曾接入共同分配；AI-06统一生产路径，AI-07探索联合编队与协同。AI-08～10提出的战术推演、多步对抗和人类定标属于未交付设想。公平探索、信息对称、能力驱动难度及不使用资源补偿是旧方案原则，已经由当前原版AI逐工作输入和差异约定替代。

共享中性路线与按需中转降低过独立寻路成本，但当时360旬没有实际签发带中转点的出征，不能据此证明港口选择改善策略。阶段观察及局部战斗估算续算曾改善小型夹具的候选覆盖，不能外推到完整搜索充分性。旧架构不作为新实现的回退执行者。

具体旧外交策略见[历史外交](diplomacy.md)；仍有效的公共提交、确定性与状态所有权边界见[DEC-AI-0001](../../decisions/DEC-AI-0001-deterministic-planning-boundary.md)。

## 证据与限制

[历史测量](../../../docs/history/performance/ai-prototype-performance-records.md)保留AOT暂停对照、预算截断、共享路线和冷暖态实验的输入、结果与限制。v112同机36旬×3次均值189.50ms／旬；暂停v116六旬样本563.17ms／旬，样本窗口和轨迹不同，不能计算等价加速比。

旧阶段计划、评分框架、测试计数及逐次实现状态已从当前文档删除，可由Git历史中的`specs/ai/`追溯。原型已退出，旧验收命令及生成物路径不再作为可运行入口。恢复任何候选方向前，应重新明确目标和验收，不直接恢复旧阶段义务。
