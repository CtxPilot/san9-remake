# BEH-CONTENT-0001：共享内容与剧本初始状态

- 状态：已确认。
- 日期：2026-11-05。
- 依据：用户要求先完成 Mod 方案第一步，整理公共定义、人物默认资料、剧本差异及初始状态，并保持20个正式剧本的有效内容不变。
- 原作证据：[RE-0007](../../research/findings/RE-SAN9PK-0007.md)说明原版全局人物编辑保存整套可编辑属性快照；本规格采用独立的重制数据组织，不复刻该覆盖方式。

## 范围与所有权

1. `ScenarioDefinitions` 持有可复用的官爵、宝物、兵法、阵形、设施、培养与事件规则及其目录资料。军事规则与地图矩阵、建筑布置分离。
2. `OfficerDefaultsCatalog` 持有稳定人物身份、显示资料与默认初始数值，不含所属、位置、身份状态、现职、逐势力忠诚及行动状态。
3. `ScenarioGeography` 持有地域、州、城市关联和领域地图地理。显示地图继续使用独立 `MapDefinition`；二者均通过显式引用归属地图，不从引用次数或运行时值比较自动搬迁。
4. `ScenarioDocument` 持有日期、势力、据点、军团、宝物持有、外交、部队、人物安置、事件进度及开局设置；并声明共享规则和人物默认值的显式差异。势力及据点当前仍由剧本声明，不将源剧本中可复用的槽号猜测为跨剧本的独立实体。
5. `ScenarioInitialState` 是组合后的会话输入，不再是磁盘 `scenario.json` 的创作契约。Core 世界及本局存档继续持有运行状态，不反向写入公共资料。

这是内容所有权整理，不提供 Mod 包发现、依赖解析、加载顺序、跨包身份、全剧本强制覆盖、内容编辑界面或伴侣038～040。已有伴侣配置和局内编辑的生效、持久化规则不变。

## 组合与差异

内容入口必须显式引用 `definitions`、`officerDefaults`、`geography` 和 `scenario`，路径受现有资源根约束。独立包可在自己的根内提供所有输入，不依赖正式20剧本或原版文件。

人物以稳定身份引用默认资料，是否加入世界完全由剧本人物集合决定；共享库中的其他人物不会自动出现。剧本可提供额外人物默认资料，不得与共享身份冲突，不继承原版槽位或数量限制。

规则与人物差异采用有类型的覆盖字段：

- 字段缺省表示继承；出现 `{ "value": ... }` 表示显式替换。
- `{ "value": null }` 可清空可空值，空集合表示明确清空；均不同于继承。
- 四项能力分别覆盖。只改智力不会把其他三项能力冻结成剧本副本。
- 规则目录及集合在本阶段按声明的类型整体替换，不建立多 Mod 集合合并协议。
- 共享默认值变化只影响没有显式覆盖的字段，不等同于全剧本强制统一。也不改写已经建立的本局世界。

组合顺序为共享定义／人物默认资料 → 剧本显式差异和初始状态 → `ScenarioInitialState`。新武将部署、史实／虚拟初始化、首旬准备继续由已有新局用例执行；读档不重做初始化。

完整内容、单独世界和势力选择入口使用同一人物组合实现。势力选择只读取必要的目录、人物和初始状态，不读取领域地图矩阵或构建军事、事件与AI规则。格式版本、缺失文件、丢失／重复人物引用、未初始化集合和完整创作契约中的未知字段必须明确拒绝，不回退到其他剧本、空目录或旧格式。

## TC101制作与发布

版本Importer明确选择正式剧本0作为共享默认资料基准，再从每个源剧本生成显式差异；该选择只是制作期的发布约定，不使运行时依赖某个剧本，也不推断它是原作权威人物库。以后源文件出现差异时须保留差异，不能用多数值抹平。

正式目录发布 `shared/definitions.json`、`shared/officer-defaults.json` 和 `shared/maps/china/geography.json`。引用同一共享地理的剧本须逐项一致；独立地图内容使用自己的地理定义。每个源剧本拆分后必须重新组合，与源转换得到的完整会话输入做结构相等核对。

`import-content --rebuild worlds` 从源重编目录内世界，全部数据、引用与差异校验通过并暂存后，先替换依赖和世界，再发布各入口；任一替换失败回滚整批。地图显示、纹理、音频、消息及界面表现文件复用。旧组合包明确拒绝，使用制作工具重建；不提供运行时兼容补值。

地图相关派生关系仍遵循[内容管线](../../docs/client-content.md)已有输入依赖和失效约定。本阶段只改变所有权和磁盘组织，不新增持久缓存或改变派生算法。

## 验收

- 20个正式剧本组合后的完整输入与拆分前语义一致，保留5名人物的基础能力差异及70名人物的已学兵法差异。
- 全量加载、世界加载与势力选择投影一致；建局和查询保留全部有效对象、未登场／死亡／休眠状态与引用。
- 覆盖继承、显式清空、四维独立覆盖、共享人物未纳入世界、剧本额外人物、非法引用和版本拒绝使用公开自制夹具验证。
- 世界整批发布失败后共享文件和各剧本均恢复，临时文件清理；未变的表现资源不被改写。
- 运行时状态、玩法规则与存档协议不因此次磁盘拆分发生变化。
