# BEH-EDITOR-0002：独立新武将人物库

- 状态：已确认；初版已实现。
- 日期：2026-11-02。
- 依据：用户要求可控制人物细节的编辑工具，头像复用游戏内已有资源；后续授权在选择势力页部署，见[新游戏创建](BEH-UI-0011-new-game.md#新武将部署与新势力)。
- 原作研究：[RE-0202](../../research/findings/RE-SAN9PK-0202.md)提供设计基线；以下为重制选择。

## 范围与所有权

标题菜单“登录新武将”进入编辑页；`--officer-editor`可直接打开。使用普通Godot控件，独立不透明背景。编辑器不创建游戏世界，也不修改剧本、新局、存档或命令脚本。

Content定义人物库契约，Application持有编辑访问的内存草稿，客户端负责控件、文件选择和原子保存。姓与名分别编辑，显示姓名由姓＋名组成；列表、搜索、亲代选项及删除提示统一使用完整姓名。人物使用稳定Guid，不继承原版固定槽位或姓名字节限制；重名合法。复制产生新身份，保留原人的所有资料。

两页分别提供基本资料和兵法。基本资料合并姓名／姓氏／字／列传、性别、头像、四维、性格、义理、野心、相性、出生年／登场年／寿命档及亲代，左侧头像、右侧双列表单、下方列传；兵法页提供九类熟练度／精通及已学兵法。

## 直接创作

不采用点数预算、随机寿命、信念生成、特殊姓名或确认时重新生成。四维、熟练度、精通和已学兵法分别保存。默认四维50、出生170、登场184、寿命档7，仅为输入初值。

辅助按钮只修改当前人物的草稿，仍须保存人物库：“能力全满”将四维设为默认能力上限100，之后可继续手动调整。兵法页只保留三个批量按钮：九类熟练度均不低于1000时显示“清空熟练度”并清零，否则显示“熟练度全满”并设为1000；九类均精通时显示“取消全精通”，否则显示“全精通”；共享目录的全部可学习兵法都已学会时显示“清空兵法”并清空已学集合，否则显示“全兵法”并加入全部可学习兵法。兵法批量操作与手动勾选共用同一筛选，单项调整后按钮文字立即跟随当前状态更新。熟练度、精通和已学兵法的辅助操作不互相改写；缺少可学习兵法时禁用“全兵法”。

四维为正整数，熟练度为非负整数，不受原版能力上限硬截断。相性0–149、义理／野心0–15、性格四档、寿命档0–7。登场年不得早于出生年，不自动按出生加14设置；寿命档不解释为固定死亡年龄。

兵法勾选项按规则语义提供可选兵法、阵形／舰船技术、营造和石兵；不把舰船自动攻击或地形决定的具体陷阱效果当作独立学习项。水军保留艨艟、楼船、斗舰；谋略保留“陷阱”，不显示其穴陷／火陷／水陷／岩陷变体。不按兵法名称或原版编号区间筛选。

打开编辑器时从内容根目录的`catalog.json`读取显式声明的共享定义及人物资料，优先读取对应的玩家副本；兵法候选由共享目录与规则的可学习语义共同确定，历史亲代候选来自共享人物资料。编辑器不读取剧本预览、剧本状态、地图、地理或运行消息，不提供参考剧本选择。共享数据缺失时明确提示，仍可编辑独立人物资料，不改用某个剧本作为后备。

亲代可引用同库人物或共享目录中的历史人物，两者互斥；历史人物保存稳定人物ID，不保存剧本身份或部署信息。同库引用拒绝自引用、循环和丢失引用，被其他人物引用为亲代时，删除须先解除引用。点击亲代打开选择窗口，可按姓名筛选人物库和共享目录中的人物；确认或双击候选才修改关系，搜索和取消不修改关系。“无亲代”始终可选。共享数据读取不改写人物库的已有输入。

## 头像

“选择头像”显示游戏现有转换头像，可分页查看、按编号搜索并选取。支持上一页／下一页、直接输入页码后按回车跳转及箭头调整；搜索时回到第一页，页码范围按筛选结果更新。预览使用游戏公共`AsyncPortrait`、裁切定义和`TextureService`缓存；从标题菜单进入时复用已有服务，独立入口加载共享纹理目录。选择头像不需要先载入剧本。

人物只保存可空的`PortraitKey`资源引用，不提供图片导入、编码、缩放或内嵌文件。不限制为某个原版编号区间。未选择时显示占位；资源缺失时显示不可用并保留引用，不静默替换。缺少转换内容仍可编辑其他人物资料。

## 旗字

人物库只保存确定的旗字资源引用或明确无字（`FlagGlyph=-1`），不保存自动／手动模式。“按姓氏自动”是编辑器全局界面偏好，默认开启，所有人物共用；正常关闭客户端时随`ui-preferences.json`统一保存，人物库保存／放弃不改变此偏好，见[界面记忆](../../docs/user-settings.md#界面记忆)。切换开关不修改人物或已有旗字，也不重算整库。

公共旗字目录由内容入口声明，包含首字默认映射和全部可选字形引用，独立于剧本和世界状态。TC101制作工具从基础人物资源派生首个非空匹配值，保留死亡／未登场人物作为来源；源槽范围和Big5约束只在Importer内，运行时不按人物编号筛选。独立作者直接维护公共目录，资源引用校验覆盖建筑与八方向部队的两种墨色。原作事实见[RE-0202](../../research/findings/RE-SAN9PK-0202.md#新武将旗字自动关联2026-11-02)。

全局自动关联开关位于顶部“编辑选项→自动旗字”，不放在单个人物资料中。旗号区位于头像操作按钮下方，显示当前旗帜图形，下方并排提供“选择”和“自动”按钮。开启自动关联时，只有姓氏实际变化且编辑完成后才更新旗字：回车确认、离开姓氏输入框、保存、复制或切换人物均完成尚未确认的编辑；输入过程中不反复改旗，回车后再次失焦不重复更新。关闭时只改姓，保留旗字。关联按首个Unicode字符取公共默认值，复姓也取首字，空姓／未知首字选无字；字符按内容原样匹配，不隐式转换繁简。

“选择旗字”窗口以旗帜预览分页展示全部字形与无字选项，点击只修改当前人物旗字，不改变全局开关；取消和翻页不修改。已选旗字保留到下次实际修改姓氏并在自动开启时完成编辑，或主动点击“自动”按当前姓氏重设；重设只作用于当前人物，不改变全局偏好。目录未就绪时禁用重设及选旗，自动开启时禁用姓氏输入；全局开关仍可关闭，头像和共享创作资料继续独立加载，其他资料仍可编辑，不把资源未就绪解释为未知姓氏。

打开人物库、载入共享资料、导入、复制、建局和读档均不按姓氏覆盖已存旗字；复制前只完成当前尚未确认的姓氏编辑。新局复制确定旗字到本局人物显示定义，存档及命令脚本新增定义保存该引用；读档直接恢复，与人物库后续修改及公共映射变化无关。自动关联偏好不写入人物库、本局定义或战局存档。

## 保存与导入

本地库为用户目录`created-officers.json`，契约版本3、UTF-8 JSON、原子替换。选人、搜索及切页不落盘；保存成功才清除未保存标志，失败保留草稿和原文件。关闭及系统窗口关闭均对未保存修改提供保存／放弃／继续选择。

读取失败时不创建替代空库，保存按钮和快捷键均不得覆盖原文件。控件编辑绑定人物身份，迟到的控件回调不能写入后来选中的人物。

数值输入在有效文本改变时立即更新当前人物草稿，不要求先按回车或移开焦点；切换人物、复制、重建表单及保存均使用最新数值。

导出只包含人物资料与资源引用。导入校验完整候选，再明确选择“更新相同身份”或“全部另建副本”；另建副本同步映射库内亲代，保留未被更新的本地人物。更新保留原列表位置，新人物按导入顺序追加；身份不按姓名猜测。复制、保存和导入导出都保留头像／旗字引用及各项独立输入，不携带编辑器自动关联偏好。旧版本或缺少旗字字段明确拒绝，不隐式补值或覆盖原文件。

## 验收

1. 独立入口和标题菜单均可编辑人物；两页、搜索、未保存关闭提示可用。部署由选择势力页独立持有，不写回人物库。
2. 头像直接从游戏资源中选择和预览，复制及文件往返保留引用，不生成个人图片文件或嵌入图片内容。
3. 长姓名及独立属性往返保持；重复身份、亲代循环和失效库内引用被拒绝，失败导入及保存不污染原数据。
4. 实际窗口由用户查看；编译和逻辑检查不替代画面验收。
