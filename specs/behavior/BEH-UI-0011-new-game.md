# BEH-UI-0011：新游戏创建与开局设定

状态：已确认

## 目标与入口

无参启动按“主菜单 → 剧本 → 玩家势力 → 开局设定 → 决定”创建新会话。设定页默认高级、史实，六项电脑战力增量为零；返回保留草稿，更换剧本重新准备势力与设定。创建期间锁定重复确认及返回，地图资源就绪后才完成确认；内容或地图读取失败时整体释放本次运行场景，保留草稿并允许重试。地图、纹理与界面共属该场景，界面先于它使用的音乐和纹理服务退出。

新游戏确认后立即以500ms连续淡出，同时在后台读取内容、校验并创建新会话；Godot节点、纹理上传和界面组装由主线程完成。地图与界面保持隐藏，全黑后若仍未就绪则继续等待；目标画面就绪且已全黑时替换场景，再以500ms淡入。准备与淡出并行，不串行增加一段淡出等待；准备较快时也必须等到全黑才替换。淡入完成前暂停新场景的演出与交互；完成后先播放既有“战略”字图和音效，字图结束才进入军师开局发言。字图与对白均不在黑屏期间消耗播放时间。转场不推进日期或额外执行领域操作；准备失败时释放新场景、淡入恢复原页面及草稿，再提示并允许重试。原作换景节拍及重制采用连续透明度的边界见[RE-0200](../../research/findings/RE-SAN9PK-0200.md#2026-10-23主菜单换景时序复核)。

最多八个玩家势力是选择界面的限制；会话按明确选择集合建立控制席位，领域身份不按编号或原版槽位推断。先激活所选预留势力、清除所选异民族身份，再执行一次性初始化与既有首旬准备。所有选中玩家及其委任军团都免于电脑补偿；仅把控制器用于自动执行不能改变选择身份。

## 新武将部署与新势力

选择势力页提供“创作新势力”“部署新武将”“取消部署”。进入该页读取已保存人物库的独立快照；返回设定页保留草稿，退出到剧本选择后丢弃本次部署。编辑器、人物库文件与剧本转换包均不被改写，历史武将编辑反映开关本次不接入。

部署支持多选，开局选择表格不显示搜索框。先选人物、再选都市；空白都市只能在野，已占都市明确选择仕官或在野。仕官包含新建势力；正式建局时按人物ID顺序，将实际在职部下对本势力忠诚设为`95-floor(min(50,与当前君主的相性环距)/2)+rnd(5)`，独立命名随机返回0至4，其余势力50；仕官起始年为开局年。草稿不投骰，未来登场及未部署亲代不提前初始化仕官忠诚；新君主自身忠诚继续显式取100。该规则采用[原作开局核对](../../research/findings/RE-SAN9PK-0202.md#开局忠诚与虚拟模式)，不套用普通登用或年度登场公式。启用自然死亡的剧本按当前开局年检查年龄15至90岁；未到登场年的部下保留地点、以未登场身份等待公共年度登场规则，届时亲属归属由世界决定，不提前锁定仕官。无视寿命的剧本也适用于新武将：不限部署年龄，立即按选择成为君主、仕官或在野，不等待未来登场年，保留作者填写的出生年、登场年与寿命档。取消部署返回未部署状态，君主须在新势力页消去或替换。

新势力页两列展示八个名额，每项选择一位新武将君主和一座空白都市，可替换、消去。君主与都市均不得重复，未配齐不能确认；返回放弃该窗口全部修改。君主可从已部署人物中提升，确认后移除其旧部下部署。消去或替换势力释放旧都市，并取消旧势力部下的仕官部署；其他新势力的身份与玩家选择保持稳定。已建势力会进入原有地图及列表，仍须在“选择势力”中选择玩家控制的势力。

新势力拥有独立君主、根军团、最低爵位、信望100；从现有50种显示色中选用最少的颜色，对其他势力关系50。初始资金为都市两次标准季度收入加3000，兵粮为两次标准年收获加30000，采用统一容量。新局建立世界时，对每个新建势力的君主所在城市执行一次增兵：扣除兵役人口的十分之一（向下取整），增加“扣除数＋5000”的士兵，单次最多增加12000，并受城市容量限制；玩家与电脑新势力均适用，新武将仅作为部下不触发。难度及显式电脑补偿在这之后执行，读档不重复增兵。[范围决策](../decisions/DEC-SCOPE-0001-scenario-scope.md)已按用户要求恢复该行为。

选择势力与新势力页复用原版按钮和头像框，采用1024×768逻辑坐标及贴图原生透明边距。新势力按两列各四项排列，君主／都市名称独立于按钮标题；选择人物、都市与取消部署复用开局蓝金列表和确认窗口。资源及布局由转换包声明，源端控件描述与坐标证据见[RE-0202](../../research/findings/RE-SAN9PK-0202.md#2026-11-01开局增兵年龄与原版布局复核)。

君主窗口以“选择武将”为题，显示“君主＋九类兵法”两行页签，概要为姓名、统率、武力、智力、政治、学得；头像跟随当前行。君主和都市采用点击行完成的单选，不显示复选框、总括按钮或额外决定，底部使用单个中止按钮及对应窄托板。部署／取消部署保留多选，不显示搜索框。都市默认地图，使用金色可选标记和灰色禁用标记，可切换一览；一览包含所在、所属、战力、内政、邻接、地域六页。窗口尺寸、标题框、页签边框、按钮与摘要按共同锚点排列；新势力按钮切换对应底部提示。都市摘要和各页复用只读查询，展示部署草稿，不创建会话、不执行开局增兵、难度补偿或首旬结算。

人物、势力与军团身份在源集合之后确定性分配，不使用原版固定登记槽或势力槽；八个名额是本页玩法限制。只将已部署人物、新势力君主及其必需的库内亲代加入本局；未部署亲代保留休眠状态，无关人物排除，不随机散入世界，也不按死亡人物处理。姓名、列传、消息人物和两类头像角色由本局新增定义装配；明确未选头像时允许留空，不影响人物有效性。

开局草稿仅用于创建世界，创建完成后不进入会话和档案。存档按“当前世界＋本局新增定义”保存：能力、兵法、亲缘、归属、位置、军团和钱粮只在世界状态中保存；新增定义仅补充人物姓名／字／列传／头像及势力的初始命名引用，不含人物库Guid、能力副本或部署输入。恢复直接使用保存的世界和新增定义，独立于当前人物库，不调用新局组合器，不重复发放资源。相同剧本且新增定义相同的读档复用显示内容；新增定义不同则重建显示。结局的“新游戏”返回主菜单，重新选择开局，不从存档反推原始创建输入。

命令脚本只声明本局新增定义及既有配置；有新增对象时须通过已有`--restore`／`--load`入口提供起点存档，不在脚本头重复嵌入世界，也不重新读取人物库。恢复与脚本边界见[存档规格](BEH-SAVE-0001-session-persistence-replay-and-headless.md)。当前采用显式部署，不实现原作独立的“选择登场武将”、未部署人物随机配置、忽略年龄模式例外或新势力编辑期间即时改写全局世界。原作事实与重制选择的差异见[RE-0202](../../research/findings/RE-SAN9PK-0202.md#选择势力页部署与创作新势力2026-11-01)。

## 难度与电脑战力

| 设置 | 一次性对象与效果 |
| --- | --- |
| 初级 | 活动普通电脑势力的每个军团账户资金、兵粮乘12/10，整数截断 |
| 高级 | 上述倍率改为14/10；每座活动普通电脑城市另加10000兵 |
| 资金、兵粮增量 | 上述账户在乘倍率后分别相加，各自按Core统一钱粮容量封顶10000000；不是周期收入倍率 |
| 内政增量 | 已占据的非玩家活动城市，包括电脑异民族；增加当前治安、商业、农业、耐久，各受自身上限约束 |
| 士兵增量 | 同上城市；与高级加兵、电脑异民族原有的开局加兵独立叠加，受城市兵力容量限制；兵役人口不变 |
| 士气增量 | 非玩家活动城市、有效地域设施及野外部队，封顶100；无主城市不加，非玩家地域设施包含无主设施 |
| 强度 | 接入既有电脑对玩家的伤害修正字段，独立于初级／高级 |

休眠、失效对象不领补偿。持续AI等待、尝试预算和军事候选读取世界保存的难度；内容中的AI难度默认只决定未显式指定设定时的新会话默认值，读档不再用它覆盖保存的难度。

## 史实与虚拟

史实保留剧本人物属性和关系。虚拟以会话种子和稳定身份顺序重建剧本原有人物中存活人物的义理0–15、野心0–15、性格0–3、寿命档0–7、相性0–149；清除亲代、血缘根改为本人；对各势力忠诚先置50，当前所属改为80–100。统率、武力、智力、政治、兵法与在职归属保留。活动在野、未发现、未登场人物从内容显式声明的候选地点中重新选址；休眠组保持预留地点。活动势力之间关系改为50，联盟与攻打约定分别保留。新武将（含新君主、部下、在野、未登场与休眠亲代）整体排除虚拟随机化，保留作者属性、亲代、血缘和部署地点；部下忠诚先按上述开局公式计算，以随机化前的君主相性为准，之后不再覆盖。此范围由建局新增人物集合表达，不依赖原作槽位或人物ID区间。

虚拟跳过特定人物配对及亲属连携加成，保留相性与人物独立加成；阻止三顾茅庐推荐、连环计前置、二乔、孙尚香婚姻、汉中王、五虎将、出师表、乌巢和赤壁的相关史实入口。已开始的事件链仍按其既有状态继续；称帝维持已采用的“虚拟可称帝”，不把虚拟当成全部事件的总开关。消息中的史实／虚拟条件读取当前世界设定，独立于剧本一般／if分类。

候选地点为剧本契约`fictionalOfficerPlaceIds`；版本Importer负责解释原作排除表，共享Core不含源编号范围。自定义内容可以独立声明候选地点与可扩展人物、势力集合。

## 开局发言与保存

首次进入各玩家势力时，依次显示开场、联盟成员／讨伐目标或敌方关系、友方关系、内政说明、必要的资源不足提示、势力目标，最后进入既有“请下令”提示。优先由现任军师发言；无军师时选当前智力最高的其他在职人物，计入伤势与宝物／官职加成，仅君主一人时由君主发言。台词、说话人绑定及条件交给内容消息图，客户端不写原版消息编号。演出只读世界，不消费玩法随机、不重复结算或写进行记录。

模式、难度、五项资源增量、电脑强度及初始玩家集合随会话保存；存档摘要显示实际模式与难度。载入恢复保存状态，不重发补偿、不重掷人物、不重新播开局介绍。命令脚本记录完整建局配置，在第一条操作前拒绝设定或初始玩家集合不符。

## 验收与范围

- 设定页确认创建对应剧本与玩家集合，正常进入地图、显示开局介绍并生成首旬自动存档；失败可重试，重复点击不会创建多局。
- 分别覆盖两种难度、普通／异民族／玩家／玩家委任／独立军团、休眠、设施与容量上限。
- 新武将忠诚覆盖相性环距0、奇数、49／50／51封顶边界、75与跨环边界；虚拟排除新武将的全部身份，保留历史人物随机化；两种模式的真实建局与保存恢复保留初始化结果。
- 固定种子下虚拟结果一致；不同种子改变随机属性，基础能力与在职归属保留；保存恢复不重复初始化。
- `verify-content`核对正式目录、世界、查询和双模式下各可选势力的开局介绍；逻辑求值不代替实际画面验收。
