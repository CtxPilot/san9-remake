# BEH-COMPANION-0002：优化伴侣基础战斗规则

- 状态：已确认
- 采用范围：004～009六项、103交战内政损失倍率及俘获概率内置规则、独立重制需求“无退路俘获加成”和四维能力选项。兵法发动、联动和成长见[025～037](BEH-COMPANION-0003-tactic-rules.md)，第二兵法系统未接入。
- 配置入口与生效时机：[伴侣面板与独立配置](BEH-COMPANION-0001-settings-and-player-domestic.md)。

## 开关与计算顺序

面板新增“战斗”页。五个开关默认关闭，兵法伤害系数默认10、范围5～10；未主动开启时保留当前原作规则。恢复默认只修改面板草稿，关闭时仅有实际变化才保存独立配置并应用。

004～007只修正武力兵法本体伤害。先累计各首发、联动成员的伤害并处理加倍，再依次处理兵数与发动者统率、远程兵法对设施减伤、伤害系数；最后沿既有流程处理效果、目标异常状态、伤害上限、电脑伤害加成和实际扣兵。附带普通攻击单独走已有结算，不乘兵法系数。设施发动武力兵法使用守军兵力和实际施法者统率。

| 编号 | 选项 | 采用行为 |
| --- | --- | --- |
| 004 | 兵数与统率增加兵法伤害 | 兵力S≥10000时，B=min(max(统率−60,0)×1000,S)，伤害T变为floor(floor((100000+B)/16)×T/6250)。保留插件的整数舍入顺序。 |
| 005 | 少兵部队减少兵法伤害 | S<10000时，T变为floor(floor(sqrt(S))×T/100)。与004按兵力区间分别生效。 |
| 006 | 远程兵法攻击设施减伤 | 弓骑、弩兵系物理兵法攻击设施时，T变为floor(T×max(1024,2048−当前耐久)/2048)，最多减半。井阑的弩兵兵法豁免。 |
| 007 | 兵法伤害系数 | T变为floor(T×K/10)，K为5～10；不作用于智力兵法、普通攻击和触发概率。 |
| 008 | 减少战斗伤兵率 | 实际兵员损失A、基础伤兵率P下，设施预期伤兵为floor(A×P×10/(100×12))，部队为floor(A×P×10/(100×13))。然后按现有伤兵容量截取，死亡为A减实际新增伤兵；兵员与溢出账目保持原语义。 |
| 009 | 提高耐久普防系数 | 普通攻击计算中，设施耐久防御项从floor(耐久×2/5)改为floor(耐久×3/5)。不改变城墙耐久伤害、兵法发动率或不含耐久项的部队属性预览。 |

008只影响公共战斗损失结算，不修改缺粮、溃散等逐日自然损耗。大数运算使用现有整数/BigInteger计算，最终仍按现有上限扣兵；不新增随机抽样。

## 交战内政损失倍率（103）

2026-11-01采用重制方案：攻防页提供一个百分比输入`CityBattleDamagePercent`，显示为“交战内政损失倍率”，默认100，范围0～int.MaxValue，不附加开关。0关闭该类损失，50减半，100保留原作1%基线，200加倍；玩家与电脑统一适用。它控制损失幅度，不是触发概率，不新增随机或消费既有随机流。

每次合格攻城交战结束，对民心、商业、开垦的当前值V分别计算`floor(V*(10000-min(P,10000))/10000)`，P为输入百分比，以64位整数计算中间量，仅最终取整。损失为原值减剩余值，不先把原作损失取整后再乘倍率；P=100与原来的`floor(V*99/100)`完全一致。按剩余值向下取整，低值下不足1点的正损失仍可能扣1，不随机舍入或累计余数；P=0直接跳过，不写城市或生成该类损失事件。高倍率最多扣完当前值，不能产生负值。

沿用已有来源与城市存活、未换属等资格，多支攻击者各自结算；没有首击豁免、每日次数累计或旬内日期门。不改变人口、属性上限、钱粮库存、攻陷民心及其他独立计略效果。城市属性通过公共写入同步维护派生信望，事件保存三项实际损失。配置仍为宿主独立输入，操作与后台分支捕获有效副本，普通存档不保存该参数；恢复后注入相同配置可精确复现。独立配置格式16、命令脚本154、规则v230，存档132、世界151及组合包243不变，无需重建内容包。

验收复用原有默认取整与信望用例，补充0／25／50／100／200及极大倍率、玩家／电脑作用域、一次取整、零随机、连续交战和换属停止；实际攻城只保留一条50%倍率的存档恢复用例，配置往返及非法负值复用现有配置测试。

## 俘获概率基础规则与四维选项

2026-11-01用户确认两项内置规则：能力变换后的个人基础俘获率至少1%，取消高能力段直接归零；围攻数量采用N16非线性修正。两项对玩家、电脑及共用战败人物结算统一生效，不提供开关。常规能力来源默认仍为当前有效武力。

设B为按既有能力变换公式计算后、取至少1的整数基础概率，N为现场合资格围攻者数量。N>0且无宝物马豁免时，取满足`k*(k+1)/2 >= N`的最小正整数k，围攻修正为`floor(B*(N+k*(k-1)/2)/k)`。倍率不先取整；然后依次处理归功阵型俘获加倍和前列3/2、中列不变、后列1/2的整数修正，再加入无城市退路加成，最终封顶100。N=1／2／3／6时，数量倍率为1／1.5／2／3；武力80、中列、无其他加成时，N=2／3／4／6／7分别为34／46／53／69／74%。全部中间量使用64位整数，k由平方根估计并用整数三角数比较确定。

1%仅为能力计算后的基础下限，不将最终概率强制抬到1%。宝物马、无合资格围攻者及其他俘获豁免继续有效；基础1经后列整数减半仍可为0。无城市退路加成默认100时仍必俘，不消耗俘获骰；有城市可退时，内置新规则会改变原版概率和后续随机结果，不宣称保留完整原版行为。

俘虏页另提供`UseHighestAbilityForCapture`，显示“四维最高值计算俘获率”，默认false（关闭）。开启时以当前有效统率、武力、智力、政治的最高值代入同一基础公式，包含伤势、宝物与官职加成；双方统一适用，单挑使用自己的独立规则。关闭仅恢复武力作为能力来源，内置的基础下限及非线性围攻仍有效。沿现有独立配置与稳定边界注入，不增加随机流或额外补掷。

验收复用原有武力、宝物马、无退路加成及恢复用例；新增围攻三角分段边界、加倍和阵位计算顺序、105／106及极大能力下限，并用三类非武力专长与伤势验证四维开关的实际捕获结果。独立配置格式16、命令脚本154、规则v230；存档132、世界151及组合包243不变，无需重建内容包。

## 无退路俘获加成（独立重制需求）

2026-11-01采用：俘虏页提供单个数值`NoRetreatCaptureBonus`，显示为“无退路俘获加成”，范围0～100、默认100，单位为百分点，无总开关。113仅对玩家取消必俘和116总人数上限的原方案均不采用；本项为独立重制需求，不记为这两个插件编号的移植。

“无退路”沿现行无其他有效城市可退的判定，不新增实际寻路或包围条件；俘获概率门与未俘人物的真实返回目的地继续分开。先按下述内置基础规则与有效能力来源计算常规概率P；无城市可退时最终概率为`min(100,P+B)`，B为本参数，有城市可退时仍为P。加成在所有常规修正之后按百分点加入，不再乘阵位或俘获加倍。宝物马、无合资格围攻者或阵位取整令常规概率为0时，无退路加成仍有效。

玩家、电脑以及野战战败、据点陷落的共同人物结算统一读取本项，不设一次战斗的总俘虏人数上限。默认100保持无城市可退必俘，且该必俘分支仍不消耗随机；概率为0或100不消耗俘获骰，其余最终概率仅消费现有`battle-personnel-capture`一次，不先掷常规再补掷加成。原有异民族等俘获豁免继续优先生效。未俘者沿现有有效据点返程或失势安置，普通势力灭亡后的清理不改变。

沿既有配置草稿、关闭才按实际变化保存及稳定边界宿主注入；普通存档不保存本项，精确恢复由宿主重新提供同一配置，后台分支捕获配置副本。独立配置格式16、命令脚本154、规则v230；存档132、世界151及组合包243不变，无需重建内容包。验收复用既有默认规则与生命周期用例，新增常规概率、加成、封顶、宝物马与有城市退路的五个算术案例，并扩展既有恢复测试验证非默认配置和默认必俘不耗骰，配置往返与上下界复用已有测试。

## 规则所有权

宿主配置交给SimulationEngine后保留为不可变有效值，不写入世界。每个事务的WorldMutation携带该配置副本，分支引擎复制相同配置，公共战斗函数使用同一组有效规则。稳定保存边界外拒绝换配置，换配置时清理旧命令准备缓存。玩家、电脑、部队与设施共用规则，未在结算中增加身份特判。

井阑豁免使用内容中独立战斗预设`CompanionCombat.SiegeTowerFormationIds`声明的阵型引用，不依赖AI选阵用途。Core结算不判断原版阵型编号。纯算术函数接受明确的兵力、发动者统率、目标耐久和攻击类别上下文，不读取界面设置或线程局部变量。

## 配置与边界

独立`companion-settings.json`使用类型化字段，系数在导入和应用边界校验。旧格式明确拒绝、不隐式迁移；读取失败保留文件并使用默认值，关闭面板仍遵守“实际变化才保存”。当前协议与内容版本见[兵法规则](BEH-COMPANION-0003-tactic-rules.md#内容与协议)，普通存档仍不携带伴侣设置。
